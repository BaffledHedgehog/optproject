Все необходимые материалы собраны в одном каталоге. 24 исходных опыта,
13 символьных тождеств и 8 тестов проверены. Новые 432 запуска — восемь методов
на 54 стартовых конфигурациях, а не 432 независимые задачи. Девять запусков
Open-loop исчерпали бюджет и сохранены в результатах.

```powershell
cd Submission/2026-11-14-v20
python -m pip install -r requirements.txt
python verify_release.py --replay
python package_release.py
```

Полный `reading_packet_v20.zip` создаётся локально. В репозитории нет его
дублирующих копий и промежуточных PDF. Для изменения статьи сначала выполните
`python build_papers.py`; он не запускает научные опыты.
Машинный указатель: [Submission/latest.json](Submission/latest.json).
