# M2: Две «лёгкие» теоремы

**Теорема A** — нижняя граница Ω(√(H₀R̃²/ε)) уже в подклассе H₁ = 0 (перенос классической цепочки Нестерова с явными константами). **Теорема B** — в размерности d = 1 задача логарифмически лёгка (бисекция), даже когда метод знает f*. Вместе они очерчивают поле для M3: H₀-член T1 обоснован без всякого H₁; H₁-член в d = 1 не получить — ядро M3 обязано использовать многомерность и сокрытие информации.

Контекст модели: класс F(H₀,H₁), FO-оракул (f, ∇f), детерминированный метод, старт — часть экземпляра, критерий f(x̂_N) − f* ≤ ε (см. M0).

## 1. Теорема A: H₁-член отключён (сужение T1a)

**Утверждение.** В классе F(H₀, 0) для любого детерминированного span-ограниченного метода (x_t ∈ x₀ + span{∇f(x₀),…,∇f(x_{t−1})}), гарантирующего зазор ≤ ε на всех экземплярах класса с R̃ ≥ dist(x₀, argmin), выполнено

$$N \;\ge\; \sqrt{\tfrac{3}{32}}\cdot\sqrt{\tfrac{H_0\tilde R^2}{\varepsilon}} \;-\; 1 \qquad (c_1 = \sqrt{3/32} \approx 0.306).$$

Знание методом f* (и любых (R̃, F₀)) не помогает: конструкция ниже это допускает.

### 1.1. Конструкция (цепочка Нестерова)

$$f_k(x) \;=\; \frac{L}{4}\Big(\tfrac{1}{2}x^\top A_k x \;-\; e_1^\top x\Big),\qquad L := H_0,$$

где A_k — трёхдиагональная матрица (2, −1) на первых m = 2k+1 координатах (на остальных координатах нулевая). Старт x₀ = 0.

### 1.2. Лемма A.1 (членство в классе с точной константой)

**‖∇²f_k‖ = (L/4)·λ_max(A_k) = L·cos²(π/(4k+4)) < L = H₀**, т.е. f_k ∈ F(H₀, 0) с точной константой H₀. (Спектр трёхдиагонали Дирихле: λ_j = 2−2cos(jπ/(m+1)); λ_max = 2+2cos(π/(m+1)) = 4cos²(π/(2(m+1))) < 4.)

*Доказательство.* Прямое вычисление гессиана и известный спектр. ∎

### 1.3. Лемма A.2 (решение)

x*ᵢ = 1 − i/(2k+2) при i ≤ 2k+1, x*ᵢ = 0 при i > 2k+1 (проверяется: A_kx* = e₁ на блоке). В частности R̃ = ‖x* − x₀‖ и

$$\|x^*\|^2 \;=\; \frac{(2k+1)(4k+3)}{12(k+1)} \;\le\; \frac{2(k+1)}{3}.$$

### 1.4. Лемма A.3 (Шур-дополнение: зазор на усечённом подпространстве)

$\min_{x:\; x_i = 0,\ i > k}\; f_k(x) - f_k^* \;=\; \frac{L}{16(k+1)}.$

*Доказательство (полное; нормировка: f_k = L·g, где g = ¼(½xᵀAx − x₁) — нормированная цепочка леммы C.1 теоремы C, поэтому всё сводится к C.2 с множителем L).* На подпространстве {xᵢ = 0, i > k}: ½xᵀAx = Σᵢ≤k xᵢ² − Σᵢ<k xᵢxᵢ₊₁ = ½x′ᵀT_k x′, где x′ = (x₁,…,x_k) и T_k — трёхдиагональ (2,−1) размера k (кросс-член x_k x_{k+1} = 0). Значит ограничение f_k|_{S_k} — в точности k-звенная цепочка того же вида, и по лемме C.1(iv) (с m := k) её минимум равен (L/4)·(−k/(8(k+1)))·… точнее: ограниченный минимум g равен −k/(8(k+1)), полный минимум g равен −m/(8(m+1)), m = 2k+1; разность

$g|_{S_k}^{\min} - g^* = \frac{1}{8}\Big(\frac{m}{m+1} - \frac{k}{k+1}\Big) = \frac{m-k}{8(m+1)(k+1)} = \frac{1}{16(k+1)},$

и умножение на L даёт утверждение. Случай k = 0: S₀ = {0}, минимум g(0) = 0, разность m/(8(m+1)) = 1/(8·2) = 1/16 = L/(16·1) при L·… ✓. ∎

*Независимый кросс-чек (другой маршрут Шура).* Квадратичное тождество f_k(x) − f_k* = (L/8)(x−x*)ᵀA(x−x*); на S_k расщепим x−x* = (u, v), v = −x*_{k+1..2k+1} фиксирован (v_i = −(k+2−i)/(2k+2)), u свободен. Минимизация по u даёт vᵀSv, S = T_{k+1} − (k/(k+1))e₁e₁ᵀ (использована точная формула (T_k⁻¹)_{kk} = k/(k+1)); тогда vᵀT_{k+1}v = (k + (k+1)² + 1)/q² = (k+1)(k+2)/q² и vᵀSv = 2(k+1)/q² = 1/(2(k+1)), q = 2k+2. Итого (L/8)·(1/(2(k+1))) = L/(16(k+1)) — то же значение ([math-proof-library: nesterov-first-order-lower-bound](https://raw.githubusercontent.com/Ephemeral6/math-proof-library/main/proofs/library/optimization/lower-bounds/nesterov-first-order-lower-bound/proof.md)). Численно: оба маршрута совпадают с прямым решением до ~1e-17 (код-канвас M2, проверка A3).

### 1.5. Лемма A.5 (span-индукция = zero-chain свойство)

Для трёхдиагональной A_k: если x ∈ span{e₁,…,e_j}, то ∇f_k(x) ∈ span{e₁,…,e_{j+1}}. Индукция по t: для span-ограниченного метода с x₀ = 0 выполнено x_t ∈ span{e₁,…,e_t}. В частности, при t ≤ k: x_t лежит в подпространстве {xᵢ = 0, i > k}, и по лемме A.3

$$f_k(x_t) - f_k^* \;\ge\; \frac{L}{16(k+1)}.$$

Информация распространяется не быстрее одной «ступени» за итерацию — метод за t шагов не знает ничего о координатах дальше t+1.

### 1.6. Завершение доказательства теоремы A

Пусть метод заявляет N итераций. Противник выбирает k := N (размерность d = 2k+1 ≥ N — dimension freedom из M0 это разрешает). Тогда после N шагов

δ := f_k(x_N) − f_k* ≥ L/(16(N+1)) ≥ 3L‖x*‖²/(32(N+1)²) = 3H₀R̃²/(32(N+1)²),

где второй шаг — лемма A.3 + ‖x*‖² ≤ 2(k+1)/3 (лемма A.2), R̃ = ‖x*‖. Успех (δ ≤ ε) требует

(N+1)² ≥ (3/32)·H₀R̃²/ε ⟹ **N ≥ √(3/32)·√I₁ − 1**. ∎

### 1.7. Бухгалтерия масштабирования (для нормировки T1)

Точно (леммы A.2–A.3): F₀ := f_k(0) − f_k* = L·(2k+1)/(16(k+1)), и прямая подстановка R̃² = (2k+1)(4k+3)/(12(k+1)) даёт

$F_0^{chain} \;=\; \frac{3}{4}\cdot\frac{H_0\tilde R^2}{4k+3},\qquad \frac{H_0\tilde R^2}{F_0} \;=\; \frac{4}{3}(4k+3),\qquad k \;=\; \frac{3}{16}\cdot\frac{H_0\tilde R^2}{F_0} - \frac{3}{4} \;\approx\; \frac{3}{16}\cdot\frac{H_0\tilde R^2}{F_0}.$

Для экземпляра с предписанными (R̃, F₀) берём k по этой формуле и при необходимости пересчитываем f̃ = αf(βx) по лемме 1 (M1): I₁, I₃ инвариантны. Замечание: сама теорема A в этой бухгалтерии не нуждается — противник выбирает k = N, а I₃ экземпляра получается каким угодно; для финальной нормировки T1 запись полезна, чтобы «уложиться» в заданные (R̃, F₀, ε).

*[Исправлено при самопроверке: в ранней версии здесь стояло H₀R̃²/F₀ = 16(k+1)/3 — неверно (происходило из приближения F₀ ≈ H₀/8); точная формула выше. Итоговая оценка k ≈ (3/16)·H₀R̃²/F₀ не изменилась, менялось только обоснование.]*

### 1.9. Подъём на произвольные детерминированные методы (закрыто)

#### 1.9.1. Почему осевая цепочка не бьёт произвольный метод

Span-ограничение в теореме A — не косметика. Зафиксированная **осевая** цепочка (U = I) проигрывает методу, знающему семейство: запрос e_j даёт ∇f(e_j)_{j+1} = −αβ²/4·[j+1 ≤ m] ≠ 0 ⟺ j+1 ≤ m, т.е. предикт «цепочка длиннее j» вычислим одним запросом. Бинарный поиск находит m за ⌈log₂ d⌉ запросов, дальше x* строится офлайн (семейство известно) — зазор 0. Демо L3 (§1.9.6): d = 40, m = 27 — зонд побеждает за 6 запросов с зазором 4.9e-17. Вывод: прятать надо не «где ступеньки», а «в каком направлении вся лестница», и прятать адаптивно.

#### 1.9.2. Протокол резистинг-оракула (Немировский–Юдин)

Оракул ведёт скрытый базис u₁, u₂, … из m = 2N+3 столбцов (k = N+1 звено цепочки) и отвечает истинными (f, ∇f) инстанса f(x) = α·g(β·Uᵀx). Обозначение: u ⊥ V означает uᵀv = 0 для всех v ∈ V:

- **Инициализация:** u₁ := e₁.
- **Запрос x_t:** зафиксировать u_{t+1} ⊥ {x₁,…,x_t, u₁,…,u_t} (любой единичный вектор вне этого подпространства). Ответить по правилу: y_s := β·(u_sᵀx_t) при s ≤ t, y_s := 0 при s > t; ответ = (α·g(y), αβ·U·∇g(y)). Заметим: ∇g(y) ∈ span{e₁,…,e_{t+1}} (span-индукция, лемма A.5), а u_{t+1} ⊥ x_t по построению, поэтому ответ использует только уже зафиксированные u₁,…,u_{t+1}.
- **Выход x̂:** дозаполнить u_{N+2},…,u_m ⊥ {x₁,…,x_N, x̂, u₁,…,u_{N+1}}.

#### 1.9.3. Лемма A.6 (консистентность)

**Каждый ответ оракула в точности равен истинным (f(x_t), ∇f(x_t)) финального инстанса.**

*Доказательство.* Для s > t все u_s строятся ⊥ x_t: u_{t+1} — при самом запросе t (x_t входит в его ограничение), u_s при s ≥ t+2 — позже, но с полным множеством запросов {x₁,…,x_N} в ограничениях; дозаполнение ⊥ всем запросам. Значит (Uᵀx_t)_s = 0 при s > t — ровно то, что оракул и подставил. При s ≤ t подставлены истинные β·u_sᵀx_t (u_s зафиксированы раньше запроса t). Квадратичная форма g на векторе с носителем ⊆ {1,…,t} не видит координат > t+1 (связи с нулями обнуляются), поэтому значение не зависит от длины вектора, на котором её вычисляют. ∎

#### 1.9.4. Лемма A.7 (счёт размерностей)

**Достаточно d ≥ 3N+4.**

*Доказательство.* Во время запросов фиксируются u₁,…,u_{N+1}; при запросе t ограничение {x₁,…,x_t, u₁,…,u_t} содержит ≤ 2t ≤ 2N векторов, поэтому u_{N+1} существует при d ≥ 2N+1. Дозаполнение: N+2 векторов u_{N+2},…,u_{2N+3} ⊥ множеству {x₁,…,x_N, x̂, u₁,…,u_{N+1}} из ≤ 2N+2 векторов; суммарно достаточно d ≥ (2N+2) + (N+2) = 3N+4. ∎

#### 1.9.5. Теорема A′ (подъём; главная для max-формы)

**Утверждение.** Пусть d ≥ 3N+4. Для любого детерминированного FO-метода, делающего не более N запросов и гарантирующего f(x̂_N) − f* ≤ ε на всех экземплярах F(H₀,H₁) (любое H₁ ≥ 0) со стартом x₀ (часть инстанса) и R̃ ≥ dist(x₀, argmin), выполнено

$N \;\ge\; \sqrt{\tfrac{3}{32}}\cdot\sqrt{I_1} \;-\; 2, \qquad I_1 = \tfrac{H_0\tilde R^2}{\varepsilon}.$

Знание методом чего угодно (f*, H₀, H₁, R̃, F₀, ε, протокола, самого факта сокрытия) не помогает: конструкция не читает метод, а только его запросы. Никакого span-условия ни на запросы, ни на выход x̂_N.

*Доказательство.* Противник применяет протокол §1.9.2 с k = N+1, m = 2N+3, β = √(Rg2(m))/R̃ (как и в лемме C.4: β = R_g/R̃; корень берётся только из Rg2(m), R̃ под корень не входит), α = H₀/β² = H₀R̃²/Rg2(m), где Rg2(m) = m(2m+1)/(6(m+1)). Финальный инстанс (лемма A.6 — консистентность) лежит в F(H₀,H₁) при любом H₁ ≥ 0: ‖∇²f‖ = H₀·cos²(π/(2(m+1))) < H₀ ≤ H₀ + H₁F₀ (проверка A1); старт x₀ = 0; dist(0, argmin) = ‖x*‖ = ‖x*_g‖/β = √(Rg2(m))·R̃/√(Rg2(m)) = R̃ точно (x* = U·x*_g/β, U ортонормальна); F₀ = α·m/(8(m+1)).

Дозаполнение даёт (Uᵀx̂)_s = 0 при s ≥ N+2, т.е. ŷ := βUᵀx̂ имеет носитель ⊆ {1,…,N+1} = {1,…,k}. По лемме A.3 (пол Шура, m = 2k+1, сужение на первые k координат):

$f(\hat x) - f^* \;=\; \alpha\big(g(\hat y) - g^*\big) \;\ge\; \frac{\alpha}{16(k+1)} \;=\; \frac{\alpha}{16(N+2)}.$

Остаётся выразить α через R̃: α = H₀R̃²/Rg2(m), Rg2(m) = (2N+3)(4N+7)/(12(N+2)) ≤ 2(N+2)/3 (⟺ (2N+3)(4N+7) = 8N²+26N+21 ≤ 8(N+2)² = 8N²+32N+32, что верно при **всех** N ≥ 0, т.к. 21 ≤ 32+6N). Отсюда floor ≥ 3H₀R̃²/(32(N+2)²), и успех требует (N+2)² ≥ (3/32)·I₁. ∎

*[Исправлено при самопроверке по внешней рецензии: в ранней выкладке стояло «8N²+32N+16 ⟺ 5 ≤ 6N» — арифметическая ошибка (правильное 8(N+2)² = 8N²+32N+32); исправленное тождество верно при всех N ≥ 0, что даже усиливает теорему — ограничение снизу на N не требуется.]*

**Замечания.** (i) Константа −2 (вместо −1 у теоремы A) — плата за k = N+1 звено: даже потратив все N запросов на зондирование, метод не вырывается за координату N+1. (ii) d ≥ 3N+4 — стандартная плата резистинг-оракула (в Nesterov 2004, Thm 2.1.7 для span-класса хватает меньшей размерности); оптимальность по d не утверждается. (iii) Носитель F₀ теоремы C (1-D cosh-блок, C.5) поднимается дословно тем же протоколом: z-направление одномерно, его можно отдать любому u_s, пол по-прежнему даёт цепочечный блок.

Честные детали. (a) В L2 зонд заключил m′ = 4 (фактически m = 27): его предикт ломается о законную коллизию пробы с уже зафиксированным u_s (протокол не обязан избегать коллизий — консистентность сохраняется, зазор только растёт; ловушка (7) код-канваса). (b) В L1 скрытие «не включилось»: AGD не покидает осевой спан, оракулу нечего прятать (U осталась осевой) — но L1 и нужен как проверка протокола и пола; силу скрытия демонстрирует контраст L2 (проигрыш) ↔ L3 (победа над той же осевой цепочкой при том же бюджете).

#### 1.9.7. Источники и сверка

- **Nemirovski–Yudin 1983** — резистинг-оракул как стандартный механизм подъёма на произвольные детерминированные методы; наш протокол — их аргумент, выписанный явно.
- **Nesterov 2004, §2.1.2, Thm 2.1.7** — конверсная теорема (нижняя граница цепочкой) для span-класса; номер сверен по независимым вторичным упоминаниям (math.stackexchange.com/questions/4942947: «Thm 2.1.7 — конверсный результат, строящий конкретную гладкую выпуклую функцию, для которой ни один метод из большого класса не может найти приближённый минимум быстрее определённой скорости»); Thm 2.1.13 — усиленная форма. Наша константа c₁ = √(3/32) самодостаточна (выводится из лемм A.1–A.5 + §1.9.5 явно), нормировка книги не используется.
- **Carmon–Duchi–Hinder–Sidford, arXiv:1711.00841** — та же механика «скрытого направления» (zero-chain ⟹ WLOG span); их формализация покрывает наш протокол.
- Наш вклад относительно стандартного аргумента — явный счёт размерности (d ≥ 3N+4), явная константа −2 и численная проверка консистентности и пола на живом прогоне оракула.

## 2. Теорема B: d = 1 лёгок (верхняя граница)

**Утверждение.** Пусть d = 1, f ∈ F(H₀,H₁) (выпуклая, |f''| ≤ H₀+H₁(f−f*), argmin ≠ ∅), старт x₀, R̃ ≥ dist(x₀, argmin). Существует метод — бисекция по знаку f' — находящий x̂ с f(x̂)−f* ≤ ε за

$$N_B \;=\; \lceil \log_2(2\tilde R / d_*) \rceil \;\;\text{ запросов},\qquad d_* := \min\big(\sqrt{\varepsilon/H_0},\; 1/\sqrt{H_1}\big),$$

где 1/√H₁ := ∞ при H₁ = 0. Методу **не нужно знать f***; H₁ нужен только для выбора d* (замечание о неизвестном H₁ — §2.5). В частности, в d = 1 H₀-член √(H₀R̃²/ε) — чистый артефакт многомерности, а H₁ вносит лишь +log₂(R̃√H₁).

### 2.1. Лемма B.1 (зазор через расстояние)

**Если d := dist(x, argmin) и H₁d² < 2, то δ := f(x)−f* ≤ H₀d²/(2−H₁d²).**

*Доказательство.* Пусть x* — ближайший к x минимизатор. Выпуклость: на отрезке [x, x*] f(z) ≤ max(f(x), f(x*)) = f(x), значит |f''(z)| ≤ H₀ + H₁(f(z)−f*) ≤ H₀ + H₁δ на всём отрезке. Второй порядок Тейлора из x* (f'(x*) = 0 — достигнутый минимум в d = 1 интерьерный):

δ = f(x) − f(x*) ≤ ½(H₀ + H₁δ)d² ⟹ δ(2 − H₁d²) ≤ H₀d². ∎

### 2.2. Алгоритм (бисекция)

Скобка [l₀, r₀] := [x₀−R̃, x₀+R̃] содержит минимизатор (R̃ ≥ dist(x₀, argmin)). Шаг s: m := (l+r)/2.
- f'(m) > 0 ⟹ все минимизаторы ≤ m (f' монотонна и положительна справа от m) ⟹ скобка [l, m];
- f'(m) < 0 ⟹ симметрично, скобка [m, r];
- f'(m) = 0 ⟹ m — глобальный минимизатор (выпуклость), стоп.

После s шагов длина скобки 2R̃/2ˢ; скобка содержит минимизатор x*, значит каждая её точка удалена от x* не более чем на d = 2R̃/2ˢ. Выход: любая точка финальной скобки.

### 2.3. Завершение доказательства

При s = N_B имеем d ≤ d*. Два связывающих случая:
- **d* = √(ε/H₀) ≤ 1/√H₁**: тогда H₁d² ≤ 1, и по лемме B.1 δ ≤ H₀d²/(2−H₁d²) ≤ H₀d² = ε ✓.
- **d* = 1/√H₁ < √(ε/H₀)**: тогда 2−H₁d² = 1 и δ ≤ H₀d² = H₀/H₁ < ε (из 1/√H₁ < √(ε/H₀) следует H₀/H₁ < ε) ✓.
- **H₁ = 0**: d* = √(ε/H₀), δ ≤ H₀d²/2 < ε ✓. ∎

### 2.5. Замечание о неизвестном H₁

Если методу известна лишь оценка H₁ ≤ H̄₁, он использует d*(H̄₁) = min(√(ε/H₀), 1/√H̄₁): при H̄₁ ≥ H₁ верно d*(H̄₁) ≤ d*(H₁), т.е. переоценка H₁ лишь уменьшает d* и увеличивает число шагов — гарантия сохраняется. Если же никакой верхней оценки H₁ нет, конечного сертификата не существует: верхняя грань H₁ не наблюдаема из FO-данных (кривизнный бюджет ‖f″‖ ≤ H₀ + H₁(f−f*) может «спать» далеко от минимизатора и не проявляться в пробных точках), и гарантия δ ≤ ε на всём классе F(H₀, ∞) недостижима никаким числом бисекций. Прагматическое правило: бисекция до ширины скобки √(ε/H₀) сертифицирована при фактическом H₁ ≤ H₀/ε — из леммы B.1 при H₁d² ≤ 1 имеем δ ≤ H₀d² ≤ ε.

## 3. Итоги M2 и следствия для M3

1. **T1a обоснована полностью, включая подъём**: H₀-член переносится на наш класс (сужение F(H₀,0) ⊂ F(H₀,H₁)) с константой c₁ = √(3/32): для span-ограниченных методов N ≥ √(3/32)·√I₁ − 1 (теорема A), для произвольных детерминированных N ≥ √(3/32)·√I₁ − 2 при d ≥ 3N+4 (теорема A′, §1.9). Любое H₁ ≥ 0, устойчивость к любой побочной информации (включая f*) — конструкция §1.9 её игнорирует.
2. **Ядро M3 обязано быть многомерным и скрывающим информацию**: в d = 1 нижней границы H₁-типа нет (теорема B — логарифмическая верхняя). Это согласуется с M1: твёрдость кандидата создаёт именно сокрытие (разделение ×22 против ×4.8–6.2 при одном F₀), а не форма функции.
3. **Согласование с кандидатом M1**: cosh-цепочка — многомерное обобщение обоих механизмов: zero-chain-структура теоремы A (лемма A.5) + зазор-зависимая кривизна (леммы 2, 7 из M1). Пер-линковый тариф 2κ² ≤ H₁ (лемма 7(d)) — тот самый «бюджет сокрытия», который в M3 будет оплачивать задержку √(L/w) на звено.
