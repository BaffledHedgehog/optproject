# M2: H₀-нижняя граница с ограниченным подуровнем и одномерная остановка

Редакция 17.10.2026. Один запрос — одна оплаченная пара (f,∇f).
R — дистанционный радиус M0. Скалярные f*,F₀ сообщаются методу;
скрытая ориентация функции не сообщается. Доказательства ниже не
заявляют нового общего механизма нижних границ: используется
классическая квадратичная цепочка и сопротивляющийся оракул.

## 1. Цепочка и её точные формулы

Пусть m≥1, Tₘ=tridiag(−1,2,−1) и

$$g_m(y)=\tfrac14(\tfrac12y^TT_my-y_1),\quad
y_i^*=1-\frac{i}{m+1},\quad
g_m^*=-\frac{m}{8(m+1)}.$$

Проверка Tₘy*=e₁ даёт минимум. Собственные значения
λⱼ(Tₘ)=2−2cos(jπ/(m+1)) положительны, а
λmax(Tₘ)/4=cos²(π/(2(m+1)))<1.
Кроме того,

$$r_m^2=\|y^*\|^2=\frac{m(2m+1)}{6(m+1)},\qquad
g_m(0)-g_m^*=\frac{m}{8(m+1)}.$$

На Sₙ={y:yᵢ=0 при i>n}, 0≤n<m, ограничение gₘ — n-звенная
цепочка. Вычитание её минимума −n/[8(n+1)] даёт точный пол

$$\min_{S_n}(g_m-g_m^*)=\frac{m-n}{8(m+1)(n+1)}.\tag{M2.1}$$

Для n=0 это просто значение в нуле. При m=2k+1,n=k пол равен
1/[16(k+1)]. Численные таблицы старой редакции не нужны для этих
алгебраических тождеств.

## 2. Span-методы: теорема A

Пусть H₀,R>0, k=N≥0, m=2N+1,
β=rₘ/R, α=H₀/β² и f(x)=α(gₘ(βx)−gₘ*), x₀=0.
Тогда f*=0, Rdist=R, f гладкая с нормой гессиана <H₀, подуровни
ограничены, а

$$F_{0,N}=\frac{3H_0R^2}{4(4N+3)}.$$

Span-метод после N запросов имеет выход в первых N координатах:
градиент трёхдиагональной цепочки расширяет носитель не более чем
на одну координату. Из (M2.1)

$$f(\hat x_N)\ge\frac{3H_0R^2}{4(2N+1)(4N+3)}
\ge\frac{3H_0R^2}{32(N+1)^2}.$$

Следовательно, для этой радиусной модели необходим
N≥√(3H₀R²/(32ε))−1, когда требуемый зазор и начальный бюджет
допускают предъявленный экземпляр. Для верхнего бюджета Δ нужен
Δ≥F₀,N. Это не утверждение для каждого точного F₀.

## 3. Произвольные детерминированные методы: теорема A′

**Утверждение.** Для H₀,R>0, H₁≥0 и каждого N≥0 положим
m=2N+3, d=3N+4. Любой детерминированный метод с ≤N FO-запросами
имеет в F(H₀,H₁) трудный экземпляр с единственным минимумом,
ограниченными подуровнями, x₀=0, Rdist=R и известными

$$f^*=0,\qquad F_{0,N}=\frac{3H_0R^2}{4(4N+7)},$$

для которого

$$f(\hat x_N)\ge\frac{3H_0R^2}{4(2N+3)(4N+7)}
\ge\frac{3H_0R^2}{32(N+2)^2}.\tag{M2.2}$$

При ε меньше правой части N запросов недостаточно. Метод может
знать H₀,H₁,R,ε,N,F₀ и саму конструкцию семейства; ориентация
скрывается оракулом. Для метода с меньшим числом запросов можно
дополнить историю фиктивными запросами до N, не меняя его выход.

### 3.1. Исправленная функция

Пусть U=[u₁,…,uₘ] имеет ортонормальные столбцы, P⊥=I−UUᵀ,
β=rₘ/R, α=H₀/β² и μ=H₀/2. Определим

$$f_U(x)=\alpha(g_m(\beta U^Tx)-g_m^*)
+\frac{\mu}{2}\|P_\perp x\|^2.\tag{M2.3}$$

Последнее слагаемое отсутствовало в прежнем подъёме. Гессиан на
range(U) равен H₀Tₘ/4, а на дополнении μI. Он положительно
определён и имеет норму ≤H₀. Поэтому функция C∞, выпукла,
коэрцитивна и лежит в F(H₀,H₁) при любом H₁≥0.
Минимум — Uy*/β, его значение 0 и норма R. Начальный зазор равен
αm/[8(m+1)]=F₀,N и не зависит от U.

### 3.2. Ответы онлайн

Зафиксируем u₁=e₁. Перед ответом на t-й запрос q_t выберем
единичный u_{t+1}, ортогональный q₁,…,q_t,u₁,…,u_t.
Введём yᵢ=β〈uᵢ,q_t〉 для i≤t и yᵢ=0 для i>t.
Оракул отвечает значением и градиентом

$$v_t=\alpha(g_m(y)-g_m^*)+
\frac\mu2\left(\|q_t\|^2-\sum_{i\le t}\langle u_i,q_t\rangle^2\right),$$

$$p_t=\alpha\beta\sum_{i\le t+1}(\nabla g_m(y))_iu_i
+\mu\left(q_t-\sum_{i\le t}\langle u_i,q_t\rangle u_i\right).$$

Все величины используют только уже выбранные столбцы. После
выхода x̂ дополним U столбцами u_{N+2},…,uₘ, ортогональными
всем q₁,…,q_N,x̂ и уже фиксированным столбцам.

### 3.3. Существование, согласованность и пол

При t-м запросе ограничений не более 2t≤2N. При финальном
дополнении их не более 2N+2; нужно m−(N+1)=N+2 столбца.
Поэтому d=3N+4 достаточно, включая N=0.

Для каждого прошлого q_t все будущие столбцы U ортогональны q_t.
Значит Uᵀq_t действительно имеет нули после t; градиент gₘ(y)
имеет нули после t+1. Кроме того,
P⊥q_t=q_t−Σᵢ≤t〈uᵢ,q_t〉uᵢ. Поэтому каждый ответ — **точный
ответ одной финальной функции (M2.3)**. Квадратичная добавка не
нарушает согласованность и не даёт дополнительной информации о
ещё не выбранных направлениях.

У выхода Uᵀx̂ нули после N+1. Применяя (M2.1) с n=N+1 и
отбрасывая неотрицательную добавку, получаем
f_U(x̂)≥α/[16(N+2)], то есть первую часть (M2.2).
Неравенство (2N+3)(4N+7)≤8(N+2)² доказывает вторую часть. ∎

Таким образом, исправление ограниченного подуровня закрыто
аналитически. Оно не решает задачу с предписанным Rlev: у этой
квадратичной функции

$$R_{\rm lev}=\sqrt{2F_{0,N}/\lambda_{\min}(\nabla^2 f_U)},$$

и отношение Rlev/R растёт с N. Тот же R нельзя подставить в обе
модели. Для точного произвольного F₀ см. отдельную теорему C.

## 4. Одномерная теорема B при известных параметрах

Пусть f∈F(H₀,H₁), d=1, Rdist≤R. Скобка [x₀−R,x₀+R]
содержит минимум. В каждом запросе её середины знак f′ сохраняет
половину, содержащую минимум; f′=0 удостоверяет оптимум.

Для ближайшего x* и r=|x−x*| выпуклость ограничивает кривизну на
отрезке величиной H₀+H₁δ. Из f′(x*)=0 следует

$$\delta\le\frac12(H_0+H_1\delta)r^2,
\qquad\delta\le\frac{H_0r^2}{2-H_1r^2}\quad(H_1r^2<2).$$

При H₀>0 положим d*=min(√(ε/H₀),1/√H₁), причём второе
число равно ∞ при H₁=0. После

$$N_B=\max\{0,\lceil\log_2(2R/d_*)\rceil\}$$

делений ширина скобки ≤d*, и любая её точка имеет зазор ≤ε.
Знание f* не нужно. При R=0 выход x₀ оптимален без запросов;
при H₀=0 глобальная функция постоянна, поэтому также достаточно
нуля запросов в классе функций без дополнительного требования
ограниченного подуровня. Это отдельные случаи, не деление на ноль.

## 5. Без знания H₁: конечный наблюдаемый сертификат

Для середины x скобки [l,r], содержащей минимум, выпуклость даёт

$$f(x)-f^*\le |f'(x)|\,(r-l)/2=:U_B.$$

Поэтому можно запрашивать середину, проверять U_B≤ε и иначе
сужать скобку по знаку производной. Это не требует H₀,H₁,f*.
Для каждой C¹-функции G=max_{[x₀−R,x₀+R]}|f′|<∞.
На k-м запросе U_B≤GR/2^{k−1}. При G,R>0 остановка наступает
не позже 1+max(0,⌈log₂(GR/ε)⌉) запросов.

G не сообщается методу: он нужен лишь для доказательства конечности
на каждом экземпляре. Единую оценку сложности класса без контроля
G или H₁ это не даёт. Прежняя фраза «конечного сертификата не
существует» была неверна. Если f* известно, зазор непосредственно
наблюдается по оплаченной функции.

## 6. Проверка и границы результата

`../Work/lower_bound_audit.py` и `test_lower_bound_audit.py` проверяют
точный пол цепочки, плотные запросы и произвольные выходы,
согласованность исправленного оракула, положительность гессиана,
цену носителя и остановку без H₁. Это внутренние конечные проверки,
не формальное доказательство и не независимое рецензирование.

Классический механизм: Нестеров, *Introductory Lectures on Convex
Optimization*, 2004; Немировский–Юдин, *Problem Complexity and Method
Efficiency in Optimization*, 1983. [Carmon и соавторы](https://arxiv.org/abs/1711.00841)
— дополнительный первоисточник о сокрытии информации в нижних границах
для другой, стационарной невыпуклой задачи; его теоремы здесь не
цитируются как готовая теорема о нашем классе.

H₁-информационная нижняя граница остаётся открытой. Численные
примеры медленных алгоритмов и нижние оценки отдельных GD-правил
не заменяют требуемую теорему для всех FO-методов.
