# Теорема C — H₀-член max-формы T1′ (часть (i))

Закрывает гарантированную часть max-формы:

**T1′ (max-форма):** N ≥ max( c₁√I₁ , c₂√I₂·log I₃ ) для инвариантов I₁ = H₀R̃²/ε, I₂ = H₁R̃², I₃ = F₀/ε.

## 0. Статус

**Доказано (этот документ):**
- **Теорема C:** N ≥ √(3/32)·√I₁ − 1 ≈ 0.3062·√I₁ − 1 для span-ограниченных детерминированных методов первого порядка (модель М0) **на всём классе F(H₀,H₁) при любом H₁ ≥ 0 одновременно**; доказательство устойчиво к любой побочной информации метода (включая знание f*, F₀, H₁, R̃, ε и даже точного описания инстанса).
- **Предложение C.5 (инвариант-носитель F₀):** 1-D cosh-блок подгоняет F₀ под предписанный инвариант за логарифмическую цену по радиусу; при этом принуждённая граница не ослабляется.
- **Следствие C.7 (инвариантно-согласованные режимы):** при точном согласовании (R̃, F₀) цепочечное семейство принуждает N ≈ min(√(3/32)·√I₁ − 1, I₃ − O(1)); полный H₀-член извлекаем iff I₃ ≥ 0.61√I₁.

**Не доказано (честно):**
- Часть (ii) max-формы, c₂√I₂·log I₃ — программа M3 (resisting oracle; cosh-цепочка M1 — носитель механизма, но её жёсткость динамическая, без информационного пола подпространства).
- Подъём span-ограничения до произвольных детерминированных методов — стандартный мостик (Немировский–Юдин 1983; Nesterov 2004, §2.1.2; Carmon et al., arXiv:1711.00841), в чеклисте (§10).
- Single-instance версия (одновременное насыщение обоих членов max на одном инстансе) — открыто; для sup-формы достаточно двух отдельных инстансов (§8).
- Извлекаем ли c₁√I₁ при I₃ < 0.61√I₁ какими-либо другими семействами — открыто (связь с фундаментальной проблемой §15 канваса M1).

Связь с уже доказанным: теорема A (канвас M2) — та же цепочка при H₁ = 0, c₁ = √(3/32), для span-ограниченных. Теорема C обобщает её: (a) любой H₁ ≥ 0 одновременно, (b) точные граничные случаи и константа −1, (c) согласование F₀ через носитель, (d) анализ режимов по I₃.

## 1. Модель (М0, рекап)

Класс **F(H₀,H₁)**: выпуклые f с достигаемым argmin, ‖∇²f(x)‖ ≤ H₀ + H₁(f(x) − f*).

Детерминированный метод первого порядка: оракул возвращает ∇f(x) в точках запроса. **Span-ограничение:** x_{t+1} ∈ x₀ + span{∇f(x₀),…,∇f(x_t)}, выход x̂_N — из того же span. Метод знает (H₀, H₁, f*, R̃, F₀, ε). Инстанс = (f, x₀, d): dist(x₀, argmin) = R̃, f(x₀) − f* = F₀, f ∈ F(H₀,H₁); размерность d и стартовая точка выбираются противником (свобода размерности). Успех: f(x̂_N) − f* ≤ ε.

## 2. Лемма C.1 — конструкция и точное решение

**Конструкция.** Для k ≥ 0 пусть m = 2k+1, A_m = tridiag(2,−1) ∈ R^{m×m}, и на R^m:

  g(x) = (1/4)·(½xᵀA_m x − x₁), то есть g(x) = (1/4)(Σᵢxᵢ² − Σᵢxᵢxᵢ₊₁ − x₁).

**(i) Производные.** ∇g(x) = (1/4)(A_m x − e₁); ∇²g = A_m/4.

**(ii) Спектр A_m (полное доказательство).** Для θ_j = jπ/(m+1), j = 1..m, положим v⁽ʲ⁾ᵢ = sin(iθ_j). Внутренние строки (2 ≤ i ≤ m−1):
  2sin(iθ) − sin((i−1)θ) − sin((i+1)θ) = 2(1 − cos θ)sin(iθ)
— прямое тригонометрическое тождество. Строка i = 1: 2sinθ − sin2θ = 2(1−cosθ)sinθ ✓ (sin2θ = 2sinθcosθ). Строка i = m: 2sin(mθ) − sin((m−1)θ) = 2sin(mθ) − sin((m+1)θ)·cos... точнее: sin((m−1)θ) = sin((m+1)θ) − 2cos(mθ)sin θ·... ; проще: sin((m+1)θ) = sin(jπ) = 0 и тождество внутренних строк формально применимо с x_{m+1} := sin((m+1)θ) = 0 ✓. Итого A_m v⁽ʲ⁾ = (2 − 2cos θ_j)·v⁽ʲ⁾, собственные значения λ_j = 4sin²(θ_j/2) > 0.
Отсюда: λ_max(A_m) = 2 + 2cos(π/(m+1)) = 4cos²(π/(2(m+1))) (j = m, тождество 1+cos t = 2cos²(t/2)).

**(iii) Гладкость.** ‖∇²g‖ = cos²(π/(2(m+1))) < 1. В частности, ∇²g ≻ 0: g строго выпукла, argmin — единственная точка.

**(iv) Точный минимум.** x*ᵢ = 1 − i/(m+1) даёт A_m x* = e₁: строка 1: 2x₁* − x₂* = 2m/(m+1) − (m−1)/(m+1) = 1 ✓; внутренние строки: 2xᵢ* − xᵢ₋₁* − xᵢ₊₁* = 0 ✓; строка m: 2x_m* − x_{m−1}* = 2/(m+1) − 2/(m+1) = 0 ✓. Тогда
  g* = g(x*) = (1/4)(½x*ᵀA_m x* − x₁*) = (1/4)(½x₁* − x₁*) = −x₁*/8 = **−m/(8(m+1))**
(использовано x*ᵀA_m x* = x*ᵀe₁ = x₁*).

**(v) Радиус.** ‖x*‖² = Σᵢ₌₁ᵐ (m+1−i)²/(m+1)² = Σⱼ₌₁ᵐ j²/(m+1)² = **m(2m+1)/(6(m+1))**.

**(vi) Начальный зазор в нуле.** g(0) − g* = **m/(8(m+1))**.

## 3. Лемма C.2 — пол Шура

Для 0 ≤ N < m пусть S_N = {x ∈ R^m : xᵢ = 0 ∀i > N}. Тогда

  min_{x∈S_N} (g(x) − g*) = (m − N)/(8(m+1)(N+1)).

**Доказательство.** На S_N: ½xᵀA_m x = Σᵢ≤N xᵢ² − Σᵢ<N xᵢxᵢ₊₁ = ½x′ᵀA_N x′, где x′ = (x₁,…,x_N) (слагаемые с i > N обнуляются, кросс-член x_N x_{N+1} = 0). Значит ограничение g|_{S_N} — в точности N-звенная цепочка, и по лемме C.1(iv) (с m := N) её минимум равен −N/(8(N+1)) (при N = 0: S_N = {0}, минимум g(0) = 0 = −0/(8·1) ✓). Разность:
  −N/(8(N+1)) + m/(8(m+1)) = [m(N+1) − N(m+1)]/(8(m+1)(N+1)) = (m−N)/(8(m+1)(N+1)). ∎

**Симметричный случай** (противник: m = 2k+1, метод: N = k): (m−N)/(8(m+1)(N+1)) = (k+1)/(8(2k+2)(k+1)) = **1/(16(k+1))**. При k = 0: m = 1, S₀ = {0}, пол = 1/16 ✓.

## 4. Лемма C.3 — индукция по span

Если x ∈ span{e₁,…,e_j} (j ≤ m−1), то ∇g(x) ∈ span{e₁,…,e_{j+1}}.

**Доказательство.** (∇g(x))ᵢ = (1/4)((A_m x)ᵢ − δ_{i1}). Строка i матрицы A_m трогает координаты i−1, i, i+1; если x имеет только координаты ≤ j, то (A_m x)ᵢ = 0 при i > j+1. ∎

**Следствие (динамика span-метода при x₀ = 0).** По индукции: x_t ∈ span{e₁,…,e_t} для всех t ≥ 0 (x₀ = 0 ∈ span{∅}; шаг: x_{t+1} ∈ x₀ + span{∇f(x₀),…,∇f(x_t)} ⊆ span{e₁,…,e_{t+1}}, т.к. каждый градиент ∇f(x_s) ∈ span{e₁,…,e_{s+1}}). В частности, **x̂_N ∈ S_N**.

Для перемасштабированной f(x) = αg(βx) (лемма C.4): ∇f(x) = αβ∇g(βx), βx ∈ span{e₁,…,e_j} ⟹ тот же вывод. Численно: нули распространяются точно (градиент строки i > j+1 есть 0.25·(2·0−0−0) = 0 в арифметике с плавающей точкой), утечка равна ровно 0 (проверка V6).

## 5. Лемма C.4 — перемасштабирование под (H₀, R̃)

Даны H₀ > 0, R̃ > 0, k ≥ 0, m = 2k+1. Пусть R_g = ‖x*‖ (лемма C.1(v)), β = R_g/R̃, α = H₀/β², f(x) = αg(βx). Тогда:

1. argmin f = x*/β; **dist(0, argmin f) = R_g/β = R̃** — радиусный инвариант точный.
2. ‖∇²f‖ = αβ²‖∇²g‖ = H₀·cos²(π/(2(m+1))) < H₀ ≤ H₀ + H₁(f−f*) (f−f* ≥ 0 по выпуклости) ⟹ **f ∈ F(H₀,H₁) при любом H₁ ≥ 0**.
3. f* = αg*; F₀ = f(0) − f* = α·m/(8(m+1)).
4. Пол: min_{x∈S_N}(f − f*) = α·(m−N)/(8(m+1)(N+1)).

**Параметризация противника (k := N, m := 2N+1).** Здесь R_g² = m(2m+1)/(6(m+1)) = (2N+1)(4N+3)/(12(N+1)), значит α = 12(N+1)H₀R̃²/((2N+1)(4N+3)), и пол при x̂_N ∈ S_N:

  f(x̂_N) − f* ≥ α/(16(N+1)) = **(3/4)·H₀R̃²/((2N+1)(4N+3))**.

## 6. Теорема C

**Теорема C.** Фиксированы H₀ > 0, R̃ > 0, ε > 0; H₁ ≥ 0 произвольно. Пусть I₁ = H₀R̃²/ε. Любой детерминированный span-ограниченный метод первого порядка (модель М0), гарантирующий f(x̂_N) − f* ≤ ε на всех инстансах класса, удовлетворяет

  **N ≥ √(3/32)·√I₁ − 1** (√(3/32) = 0.306186…).

**Доказательство.** Пусть N ≥ 0 таково, что (N+1)² < (3/32)·I₁ (иначе утверждаемая граница слабее N+1 ≥ √(3/32)√I₁ и нечего доказывать). Противник предъявляет инстанс леммы C.4 с k := N, m := 2N+1, d := m (свобода размерности: d = 2N+1 ≥ N+1), стартом x₀ = 0. Инварианты: dist(x₀,argmin) = R̃ ✓; f ∈ F(H₀,H₁) при данном H₁ (лемма C.4.2) ✓; F₀ = αm/(8(m+1)) — методу сообщается; f* сообщается.

По лемме C.3 выход метода x̂_N ∈ S_N, значит по леммам C.2/C.4:

  f(x̂_N) − f* ≥ (3/4)·H₀R̃²/((2N+1)(4N+3)) = ε·(3/4)I₁/((2N+1)(4N+3)).

Осталось сравнить константы: посылка даёт (3/4)I₁ > 8(N+1)² = 8N²+16N+8, а

  8N²+16N+8 − (2N+1)(4N+3) = 8N²+16N+8 − (8N²+10N+3) = 6N+5 > 0.

Значит f(x̂_N) − f* > ε: метод с N запросами обязан ошибиться. Контрапозиция: успех ⟹ (N+1)² ≥ (3/32)I₁, т.е. N ≥ √(3/32)·√I₁ − 1. ∎

**Крайние случаи.** N = 0: посылка I₁ > 32/3; пол = (3/4)I₁ε/3 = I₁ε/4 > (32/3)ε/4 = 2.67ε ✓. k = 0 (m = 1): формулы лемм покрывают случай, пол = α/16 = H₀R̃²/4.

**Точность константы.** Неравенство 6N+5 > 0 — единственный зазор между посылкой и выводом; отношение пола к ε на пороге: 8(N+1)²/((2N+1)(4N+3)) = 1 + (6N+5)/((2N+1)(4N+3)) = 1 + 3/(4N) + O(1/N²) → 1. Константа √(3/32) не улучшаема внутри этой конструкции; слагаемое −1 — цена точности (асимптотически N ≥ (√(3/32) − o(1))√I₁).

**Информационная жёсткость (важно).** Аргумент провала использует только два факта: (a) геометрию x̂_N ∈ S_N (следствие span-ограничения и структуры ∇g) и (b) значение f на S_N. Никакие знания метода — f*, F₀, ε, H₁, R̃, точное описание инстанса, любая побочная информация — не меняют эти два факта. Следствия:
- граница верна тем более для методов, наделённых **большей** информацией, чем предполагает М0;
- граница **H₁-равномерна**: один и тот же инстанс (лемма C.4) лежит в F(H₀,H₁) при всех H₁ ≥ 0, поэтому H₀-член нижней границы не деградирует с ростом H₁ или знанием H₁;
- знание f* бесполезно против этой конструкции: спрятано не значение цены, а **где** лежат ступеньки (координатная структура S_N).

## 7. Предложение C.5 — инвариант-носитель F₀

**Задача.** При согласованных инвариантах предписанное F₀ может превышать естественное F₀ цепочки; нужен инстанс с точным f(x₀)−f* = F₀ и dist(x₀,argmin) = R̃.

**Конструкция.** f(x,z) = f₁(x) + h(z), x ∈ R^m, z ∈ R; старт (0, z₀); носитель

  h(z) = (c₀/κ²)(cosh(κz) − 1), 0 < c₀ ≤ H₀, 0 < κ² ≤ H₁ (острый выбор: c₀ = H₀, κ² = H₁).

(Обозначения: κ — частота носителя, греческая каппа; k — ниже число звеньев цепочки. Это разные величины; в частности, нигде не предполагается κ = k. Членство использует только κ² ≤ H₁.)

**(1) Членство носителя.** h″(z) = c₀cosh(κz) = c₀ + κ²h(z), h* = 0 (в z = 0). Условие h″ ≤ H₀ + H₁h ⟺ (c₀−H₀) + (κ²−H₁)h ≤ 0 ∀h ≥ 0 ⟺ c₀ ≤ H₀ и κ² ≤ H₁. Замечание: для **одномерного** блока нет фактора 2 (в отличие от cosh-цепочки леммы 7 M1, где связь звеньев требует κ² ≤ H₁/2).

**(2) Членство f (блочно-диагональный гессиан, ‖∇²f‖ = max норм блоков).** Цепочечный блок: ‖∇²f₁‖ ≤ H₀cos² < H₀ ≤ H₀ + H₁(f−f*) ✓. Носитель: c₀ + κ²h(z) ≤ H₀ + H₁(f₁−f₁* + h(z)) = H₀ + H₁(f−f*) ✓ (c₀ ≤ H₀, κ² ≤ H₁, f₁−f₁* ≥ 0). Членство возможно с равенством (в точках (x*, z)) — допустимо, определение использует ≤. Маржин в старте: H₀ + H₁F₀ − h″(z₀) = (H₀−c₀) + H₁F₀chain + (H₁−κ²)h(z₀) > 0.

**(3) Согласование F₀.** F₀total(старт) = F₀chain + h(z₀), где точно (леммы C.4 и C.1(vi), m = 2k+1):

  **F₀chain = (3/4)·H₀Rch²/(4k+3)**, Rch² = R̃² − z₀² (радиус цепочки = остаток радиуса).

z₀ определяется самосогласованным уравнением z₀ = Φ(z₀), где Φ(z) := arccosh(1 + κ²ΔF(z)/c₀)/κ, ΔF(z) = F₀ − (3/4)H₀(R̃²−z²)/(4k+3) (эквивалентно: cosh(κz₀) = 1 + κ²ΔF(z₀)/c₀).

**Существование (IVT).** Достаточно двух условий: **(A1)** ΔF(0) = F₀ − F₀chain(R̃²) ≥ 0 (носитель только добавляет бюджет; выбор k в C.7 это обеспечивает — в режиме 1 порог F₀chain(k*) ≤ F₀ совпадает с условием режима, в режиме 2 z₀ ≈ 0) и **(A2)** F₀ ≤ h(R̃) = (c₀/κ²)(cosh(κR̃)−1). При (A1) Φ непрерывна на [0, R̃] (ΔF(z) ≥ ΔF(0) ≥ 0, аргумент arccosh ≥ 1); на концах: Φ(0) ≥ 0 и Φ(R̃) = arccosh(1+κ²F₀/c₀)/κ ≤ R̃ ⟺ (A2). Значит g(z) := Φ(z) − z непрерывна, g(0) ≥ 0 ≥ g(R̃), и по теореме о промежуточном значении существует z₀ ∈ [0, R̃]; при нём Rch² = R̃²−z₀² ≥ 0 и ΔF(z₀) ≥ 0 ✓. Единственность не требуется — годится любая неподвижная точка. Существенность (A2): это не внешнее ограничение конструкции, а максимум самого класса — для любого f ∈ F(H₀,H₁) с dist(x₀,argmin) = R̃ выполнено F₀ ≤ (H₀/H₁)(cosh(√H₁R̃)−1) (экстремаль w″ = H₀ + H₁w, w(0) = w′(0) = 0), что при остром выборе c₀ = H₀, κ² = H₁ в точности совпадает с h(R̃): несогласуемый F₀ не реализуем вообще никаким инстансом класса.

*[Исправлено по внешней рецензии: в ранней редакции существование заявлялось через «сжимаемость» (F₀chain зависит от z₀ квадратично слабо) без доказательства — заменено на явный IVT-аргумент с условиями (A1)–(A2).]*

**(4) Цена — логарифм.** z₀ = arccosh(1+κ²ΔF/c₀)/κ ≈ (1/κ)·ln(2κ²ΔF/c₀): радиусная цена растёт лишь как логарифм ΔF (квадратичный носитель z₀ = √(2ΔF/c₀) съел бы весь радиус; cosh-носитель — единственный способ иметь одновременно большой F₀ и большой H₀-радиус). Радиусный множитель принуждённой границы: c₁eff = √(3/32)·√(1 − z₀²/R̃²).

**(5) Span-индукция выживает.** ∇f(x,z) = (∇f₁(x), h′(z)); каждая x-компонента градиента лежит в span{e₁,…,e_{j+1}}, если x-часть текущей точки в span{e₁,…,e_j}; z-направление одномерно. Итого каждый запрос расширяет x-span не более чем на одну координату: после N запросов x-часть x̂_N ∈ span{e₁,…,e_N} = S_N. Так как h ≥ h* = 0:

  f(x̂_N) − f* ≥ f₁(x̂-часть) − f₁* ≥ пол_цепочки(N).

**Носитель не ослабляет принуждённую границу**; он лишь тратит запросы метода (его собственная сложность ≈ log₂ — см. (6)).

**(6) Носитель лёгок (теорема B, канвас M2).** Бисекция по z: скобка ширины 2z₀, d* = min(√(ε/H₀), 1/√H₁), N_B = ⌈log₂(2z₀/d*)⌉ — логарифмическая; знание f* не нужно.

**(7) Случай H₁ = 0.** Носитель вырождается в квадратичный (κ → 0: h(z) → c₀z²/2), z₀ = √(2ΔF/c₀); согласование возможно лишь при F₀ ≤ H₀R̃²/2 — но это и так необходимо: для любого f ∈ F(H₀,0) выполнено F₀ ≤ H₀·dist²/2 (из H₀-гладкости). Ограничение согласования совпадает с ограничением класса.

## 8. Следствия

**C.6 (max-форма, часть (i) закрыта).** Для sup-формы нижней границы по инстансам с данными инвариантами:

  sup N ≥ max( √(3/32)√I₁ − 1 , [M3: c₂√I₂·log I₃] ).

Часть (i) — теорема C (доказана). Часть (ii) — программа M3. Для sup-формы композиция не нужна (два отдельных инстанса насыщают члены по отдельности); single-instance версия (одновременность на одном инстансе) — открыто, требует серийной конструкции (§15.6 канваса M1).

**C.7 (инвариантно-согласованные режимы; точное согласование (R̃, F₀)).** Пусть инвариант I₃ = F₀/ε предписан точно. Цепочечное семейство (+носитель при необходимости) принуждает

  **N ≈ min( √(3/32)·√I₁ − 1 , I₃ − O(1) )**,

с двумя режимами:
- **I₃ ≥ (3/16)·√(32/3)·√I₁ ≈ 0.6124·√I₁ (режим полного члена):** противник берёт k* = ⌊√(3/32)·√I₁⌋, носитель добирает ΔF = F₀ − F₀chain(k*), z₀ ≈ (1/√H₁)ln(2H₁ΔF/H₀); принуждённо N ≥ √(3/32)·√(1−z₀²/R̃²)·√I₁ − 1 — полный H₀-член с лог-деградацией по радиусу (уходит при H₁R̃² ≳ ln²(F₀·H₁/H₀)).
  Порог: F₀chain(k*) = (3/4)H₀R̃²/(4k*+3) ≈ 0.6124·√(H₀R̃²ε) ⟹ нужно F₀/ε ≥ 0.6124√I₁.
- **I₃ < 0.61·√I₁ (режим F₀-бюджета):** длинная плоская цепочка: k_min ≈ (3/16)·I₁/I₃ звеньев (из F₀chain(k) ≤ F₀: 4k+3 ≥ (3/4)I₁/I₃), полный радиус, носитель вырожден (z₀ ≈ 0, ΔF ≈ 0). Принуждённо **N ≈ I₃ − O(1) = F₀/ε − O(1)**.
- **Структурная шапка:** при любом согласованном F₀ цепочечное семейство не может принудить более ~F₀/ε запросов: из F₀chain ≤ F₀ следует (3/16)·I₁c/k ≤ I₃ для любой допустимой (k, Rch), т.е. порог пола всегда достижим методом за ≲ I₃ запросов. H₀-член √(H₀R̃²/ε) насыщается только когда на него хватает **бюджета начального зазора** F₀.

Связь с фундаментальной проблемой (§15 канваса M1, таблица B): наблюдение «адаптивный метод не платит H₀/ε-рост при малых ε» — **совместимо** со структурой C.7: у кандидата §9 I₃ = F₀/ε огромен, но H₀-член цепочки не насыщается им по другой причине (лапласианово дно 15.3), а в согласованном мире жёсткость H₀-члена ограничена бюджетом I₃. Открытый вопрос: существует ли не-цепочечное семейство, насыщающее c₁√I₁ при I₃ < 0.61√I₁.
