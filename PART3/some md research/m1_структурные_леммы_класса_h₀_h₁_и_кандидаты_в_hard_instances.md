# M1: геометрия глобального класса и границы выводов

Исправлено 17.10.2026. Модель Rdist/Rlev — M0. Прежние таблицы
сохранены в истории заметок. Не приложенные TypeScript-канвасы
не считаются воспроизведённым кодом проекта.

## 1. Масштабирование

Для f̃(x)=αf(βx), α,β>0:

$$\widetilde H_0=\alpha\beta^2H_0,\quad
\widetilde H_1=\beta^2H_1,\quad
\widetilde F_0=\alpha F_0,\quad
\widetilde R_{\rm dist}=R_{\rm dist}/\beta,\quad
\widetilde R_{\rm lev}=R_{\rm lev}/\beta.$$

Следует из ∇²f̃=αβ²∇²f(βx). При ε̃=αε инвариантны
H₀R²/ε,H₁R²,F₀/ε для одного фиксированного типа радиуса.
Масштабирование не позволяет независимо подогнать все отношения
и не переводит Rdist в Rlev.

## 2. Потолок роста

Для x*∈argmin f, единичного u и h(t)=f(x*+tu)−f* имеем
h(0)=h′(0)=0, h≥0, h″≤H₀+H₁h. При H₁>0 положим
ψ(t)=(H₀/H₁)(cosh(√H₁t)−1). Для w=h−ψ:

$$w(t)=\int_0^t\frac{\sinh(\sqrt{H_1}(t-s))}{\sqrt{H_1}}
\big(w''(s)-H_1w(s)\big)\,ds\le0.$$

Значит h(t)≤ψ(t); при H₁=0 предел — H₀t²/2. Выбор ближайшего
минимума даёт совместимость F₀≤Ψ(Rdist) из M0. Cosh достигает
равенства в одномерном случае. Это ограничение на радиус, а не
доказательство необходимой длины цепочки, размерности или сложности.

При H₀>0 подуровень {f−f*≤c} содержит шар радиуса
arcosh(1+H₁c/H₀)/√H₁ вокруг каждого минимума; при H₁=0 радиус
√(2c/H₀). Дно нельзя произвольно спрятать в узкой щели.

## 3. Нулевая базовая кривизна

При H₀=0 тот же интегральный аргумент даёт h≤0; вместе с h≥0
получаем f≡const на ℝᵈ. С требованием ограниченного подуровня
нет нетривиальных экземпляров положительной размерности.
Без достигаемости eˣ даёт непостоянный пример H₀=0,H₁=1, inf f=0.
На компакте относительно условного минимума возможна непостоянная
функция с граничным оптимумом; это другой случай основной статьи.

## 4. Точная градиентная оценка

Для глобальной модели верно

$$\|\nabla f(x)\|^2\le2H_0F(x)+H_1F(x)^2,\qquad F=f-f^*.$$

При H₁>0 применим сравнение на всём луче
x−tu, u=∇f(x)/‖∇f(x)‖, с c=H₀/H₁, k=√H₁:

$$0\le F(x-tu)\le(F(x)+c)\cosh(kt)
-\frac{\|\nabla f(x)\|}{k}\sinh(kt)-c.$$

Минимизация полученной границы ‖∇f(x)‖ по t>0 даёт
√(2H₀F+H₁F²). При H₁=0 используется квадратичный предел,
при H₀=0<H₁ — t→∞; стационарный случай очевиден.
Прежнее 2(H₀+H₁F)F тоже верно, но не точно по коэффициенту H₁.
Cosh достигает точных коэффициентов при H₀,H₁>0, квадратичная
функция — при H₁=0, экспонента — при H₀=0 без достигнутого минимума.
Сам принцип самоограничения известен ранее; границы новизны — в статье
и литературном обзоре. Отношение 0.5 на одном кандидате не доказывает
точности константы по классу.

## 5. Необходимая интерполяция

На {F≤c} гессиан ограничен H₀+H₁c. Для любых x,y выпуклость
ограничивает F на отрезке максимумом его концов, поэтому

$$f(y)\le f(x)+\langle\nabla f(x),y-x\rangle
+\tfrac12(H_0+H_1\max\{F(x),F(y)\})\|y-x\|^2.$$

Это необходимое условие. Достаточность для продолжения конечных
данных до глобальной выпуклой C²-функции с заданным минимумом и
радиусом не доказана. PEP на этих ограничениях — релаксация класса.

## 6. Cosh-цепочка: доказанное членство

Для d≥2, c₀,cₐ,k>0:

$$f(x)=\sum_{i=1}^{d-1}\frac{c_0}{k^2}
(\cosh(k(x_{i+1}-x_i))-1)
+\frac{c_a}{k^2}(\cosh(kx_d)-1).$$

Минимум 0 достигается только в нуле; подуровни ограничены.
Обозначим gᵢ≥0 звеньевые значения, gₐ≥0 якорь, vᵢ=eᵢ−eᵢ₊₁:

$$\nabla^2f=\sum_i(c_0+k^2g_i)v_iv_i^T
+(c_a+k^2g_a)e_de_d^T\succeq0.$$

Суммы модулей строк: 2w₁ на первом конце, 2wⱼ₋₁+2wⱼ внутри,
2wᵈ₋₁+wₐ на последнем конце. Отсюда

$$\|\nabla^2f\|\le4c_0+c_a+2k^2f.$$

Доказано членство в F(4c₀+cₐ,H₁) при 2k²≤H₁. Для большого
первого звена луч Рэлея u=(e₁−e₂)/√2 даёт
‖∇²f‖≥2(c₀+k²g₁); это требует 2k²≤H₁ для данного семейства.
При d=1 рассматривается отдельный якорь, не формула концов цепочки.

## 7. Чего численный кандидат не доказывает

Исторические frozen/адаптивные сравнения относятся к конкретным
алгоритмам. Задержка ≈√(L/w) на звено у frozen AGD не является
универсальной задержкой раскрытия информации произвольным FO-методом.
Если метод знает осевое семейство с минимумом ноль, он может выдать
ноль сразу. Нужен отдельно доказанный механизм сокрытия базиса и
пола ошибки на всех возможных выходах.

Слабый якорь создаёт собственную обусловленность, но не доказывает
сложность √(H₁R²)log(F₀/ε). Прежние утверждения о «насыщении»
H₁-информационной границы по численным таблицам отозваны.

## 8. Композиция и план M3

Прямое произведение даёт оба градиента за один запрос. Это существенно
для точных констант, но для двух членов A+B≤2max(A,B): различия
порядков max и суммы нет. Два трудных семейства на одинаковых
параметрах уже дают Ω(A+B). Последовательный гейт не обязателен.

Основная задача — H₁-информационная нижняя граница на согласованном
классе либо контрпример к гипотезе. Отдельно согласуются Rdist/Rlev
и точный F₀. Статус: структурные неравенства доказаны; H₀-нижняя
граница дистанционной модели — M2/C; H₁-граница и достаточная
интерполяция открыты. Абсолютный библиографический приоритет не установлен.
