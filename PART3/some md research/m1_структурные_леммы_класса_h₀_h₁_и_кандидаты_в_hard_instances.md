# M1: Геометрия класса (H₀,H₁)

Рабочий документ ступени M1 плана исследования. Содержит: структурные леммы класса с доказательствами (разделы 1–7), «правила устройства плохих долин» (раздел 8), эталонный кандидат в hard instances с измеренной твёрдостью (разделы 9–11), негативные результаты (раздел 12), статус чтения (раздел 13), решение о переходе к M2 (раздел 14) и фундаментальную проблему H₀-члена с вопросом композиции sum-vs-max (раздел 15). Все численные утверждения получены симуляцией (порт ноутбука, валидирован на известных числах примера 2: 6049/793 против 6047/728 из ноутбука — расхождение только из-за честного сертификата H₀c = 4c₀+cε).

Обозначения: F(x) := f(x) − f* (зазор в точке), F₀ = F(x₀), R̃ ≥ dist(x₀, argmin f), I₁ = H₀R̃²/ε, I₂ = H₁R̃², I₃ = F₀/ε.

## 1. Лемма 1 (масштабная инвариантность и параметры задачи)

**Утверждение.** Пусть f ∈ F(H₀, H₁), α, β > 0, f̃(x) := α·f(βx). Тогда f̃ ∈ F(αβ²H₀, β²H₁) (f̃* = αf*). Более того: I₁, I₂, I₃ одинаковы для (f, x₀) и (f̃, x₀/β) с ε̃ = αε, и

√(H₀R̃²/ε) = √I₁,  √(H₁R̃²) = √I₂,  log(F₀/ε) = log I₃.

*Доказательство.* Прямое вычисление: ∇²f̃(x) = αβ²∇²f(βx) ≤ αβ²(H₀ + H₁(f(βx)−f*)) = αβ²H₀ + β²H₁·(f̃(x)−f̃*). Радиус и зазоры: R̃ → R̃/β, F → αF, ε → αε; произведения H₀R̃²/ε, H₁R̃² инвариантны. ∎

**Следствия.** (i) Целевая теорема T1 — утверждение только об инвариантах: N ≥ c₁√I₁ + c₂√I₂·log I₃. Любое доказательство можно вести в нормализации, удобной для вычислений (мы ниже неявно работаем в нормализации I₂ = O(1)·d). (ii) Отношение δ := H₁F₀/H₀ — третья безразмерная комбинация, «сила зависимости кривизны от зазора».

**Численная верификация.** Рестартная схема на кандидате (раздел 9) и на его образе при α = 4, β = 1/√2 (H₀: 1.0000025 → 2.000005, H₁: 2 → 1, R̃: 12 → 16.97, F₀ ×4): **393 итераций = 393 итераций**, точно.

## 2. Лемма 2 (cosh-потолок роста; экстремальный профиль)

**Утверждение.** Пусть f ∈ F(H₀,H₁), x* ∈ argmin f, u — единичный вектор, g(t) := f(x*+tu) − f*, t ≥ 0. Тогда

g(t) ≤ (H₀/H₁)·(cosh(√H₁·t) − 1)   (H₁ > 0),   g(t) ≤ H₀t²/2   (H₁ = 0).

*Доказательство.* g(0) = g'(0) = 0, g ≥ 0, g''(t) = uᵀ∇²f(x*+tu)u ≤ H₀ + H₁g(t). Пусть y — решение ОДУ y'' = H₀ + H₁y, y(0) = y'(0) = 0, т.е. y(t) = (H₀/H₁)(cosh(√H₁ t) − 1). Для w := g − y: w'' ≤ H₁w, w(0) = w'(0) = 0. Представление через функцию Грина:

w(t) = (1/√H₁)·∫₀ᵗ sinh(√H₁(t−s))·(w''(s) − H₁w(s)) ds ≤ 0,

поскольку ядро неотрицательно, а w'' − H₁w ≤ 0. Итого g ≤ y. ∎

**Экстремальность.** Профиль f(x) = (H₀/H₁)(cosh(√H₁ x) − 1) (пример 1 ноутбука) даёт равенство f'' = H₀ + H₁f: cosh — в точности экстремальное решение, потолок достигается.

**Следствие (запрет узких щелей).** Подуровень {f ≤ f*+c} содержит шар радиуса r_c = arccosh(1 + H₁c/H₀)/√H₁ ≈ √(2c/H₀) (при малых c) вокруг каждого минимизатора. «Дно нельзя спрятать в щели»: ε-целевое множество всегда жирное.

**Численно** (кандидат раздела 9, луч вдоль e₁): t=8: 71.1 ≤ 20484; t=12: 1210 ≤ 5.86·10⁶ — с запасом (луч растёт с «половинной частотой» κ = √H₁/2).

## 3. Предложение 3 (пустота класса (0,H₁) при достигаемом минимуме)

**Утверждение.** Если f ∈ F(0,H₁) и argmin f ≠ ∅, то f ≡ const.

*Доказательство.* В обозначениях леммы 2 при H₀ = 0: g'' ≤ H₁g, g(0) = g'(0) = 0, g ≥ 0. Та же функция Грина (y ≡ 0) даёт g(t) ≤ 0, а g ≥ 0 ⇒ g ≡ 0 вдоль каждого луча из каждой точки argmin по всем направлениям. ∎

**Граница класса.** Без требования достигаемости минимума нетривиальные функции есть: f(x) = e⁻x имеет f'' = e⁻x = f − inf f, т.е. f ∈ F(0,1) с недостигаемым inf = 0. Значит, вырождение — не артефакт определения, а следствие достигаемости.

**Следствие (переформулировка ядра работы).** Подцель T1b плана («подкласс H₀ = 0») пуста и как цель бессмысленна. Честная переформулировка ядра M3: **большой-δ режим** — H₀ > 0 фиксировано, δ = H₁F₀/H₀ → ∞, доказать N ≥ c·√I₂·log I₃ (H₁-член T1) на подсемействе с δ ≥ δ(I₂) (см. следствие 4: δ ограничено сверху через I₂).

## 4. Следствие 4 (бюджет цепочки: δ ≤ cosh(√I₂) − 1)

**Утверждение.** Для любого экземпляра класса: H₁F₀/H₀ ≤ cosh(√(H₁R̃²)) − 1, т.е. δ ≤ cosh(√I₂) − 1.

*Доказательство.* Применить лемму 2 к лучу от ближайшего к x₀ минимизатора через x₀ при t = dist(x₀, x*) ≤ R̃: F₀ ≤ (H₀/H₁)(cosh(√H₁R̃) − 1). ∎

**Численно** (кандидат, старты a·e₁): a=8: δ=142 ≤ 4.1·10⁴ (I₂=128); a=10: δ=588 ≤ 6.9·10⁵ (I₂=200); a=12: δ=2420 ≤ 1.17·10⁷ (I₂=288). ✓

**Интерпретация (важно для формы теоремы).** Сильная зависимость кривизны от зазора (большое δ) **принудительно требует длинной цепочки**: √(H₁)R̃ ≥ arccosh(1+δ) ≈ ln(2δ). Поэтому H₁-член целевой теоремы имеет вид √(H₁R̃²)·log I₃ = √I₂·log I₃ ≥ ln(2δ)·log I₃ — форма члена не произвольна, она навязана геометрией класса. Это первый содержательный ответ M1 на вопрос «как могут быть устроены плохие долины»: сложность H₁-механизма измеряется длиной цепочки √I₂.

## 5. Лемма 5 (градиентная оценка через зазор)

**Утверждение.** Для любого x: ‖∇f(x)‖² ≤ 2(H₀ + H₁F(x))·F(x).

*Доказательство.* Пусть L̃ := H₀ + H₁F(x), g := ∇f(x) ≠ 0. Определим t* := sup{t ∈ [0, 1/L̃] : f(x − sg) ≤ f(x) ∀s ∈ [0,t]}. На отрезке [x, x−t*g] выпуклость даёт f ≤ f(x), значит ‖∇²f‖ ≤ L̃, и лемма о спуске даёт f(x−tg) ≤ f(x) − t‖g‖² + (L̃/2)t²‖g‖². При любом t < min(t*, 1/L̃] правая часть строго меньше f(x) (ибо t < 2/L̃), а тогда по непрерывности f ≤ f(x) и чуть за t* — противоречие с максимальностью t*. Значит t* = 1/L̃, и f* ≤ f(x − g/L̃) ≤ f(x) − ‖g‖²/(2L̃), откуда ‖g‖² ≤ 2L̃F(x). ∎

**Численно** (кандидат, луч e₁): отношение ‖∇f‖²/граница = 0.25 (a=12), 0.31 (a=3), 0.45 (a=1), 0.50 (a=0.05), 0.096 (неколлинеарный sin-зонд). Константа 2 неулучшаема: у дна отношение → 0.5, т.е. ‖∇f‖ ≈ √(2H₀·F).

**Следствие (запрет крутых стен у дна).** Вблизи минимума градиент обязан гаснуть как √F: «стена» с градиентом ≫ √(H₀ε) на уровне ≤ ε невозможна. Ещё один запрет на геометрию плохих долин (в дополнение к запрету узких щелей из леммы 2).

## 6. Лемма 6 (локализация кривизны; интерполяционная форма класса)

**Утверждение.** (a) На подуровне {x : F(x) ≤ c} функция f является (H₀ + H₁c)-гладкой. (b) Для любых x, y:

f(y) ≤ f(x) + ⟨∇f(x), y−x⟩ + ½·(H₀ + H₁·max{F(x), F(y)})·‖y−x‖².

*Доказательство.* На отрезке [x,y] выпуклость даёт f(z) ≤ max(f(x), f(y)), т.е. F(z) ≤ m := max{F(x), F(y)}; значит ‖∇²f(z)‖ ≤ H₀ + H₁m на всём отрезке; проинтегрировать неравенство Тейлора второго порядка вдоль отрезка. ∎

**Роли.** (i) Обоснование рестартных схем (верхняя граница Лобанова — в точности этот принцип: в фазе с сертифицированным зазором Δₛ кривизна ≤ H₀+H₁Δₛ). (ii) **Честность резистинг-оракула (ядро M3)**: любой набор ответов оракула обязан попарно удовлетворять (b) с скрытым f* — это необходимые интерполяционные условия класса F(H₀,H₁). (iii) Форма ограничений для PEP-анализа (d ≤ 3) в M3.

**Открытая задача (переносится в M3).** Достаточность: полная iff-характеризация F(H₀,H₁) первого порядка — аналог Lemma 2.5 Vankov et al. для (L₀,L₁)-класса (у них: ‖∇²f‖ ≤ L₀+L₁‖∇f‖ ⟺ семейство попарных неравенств с φ(t) = eᵗ−t−1 и сопряжённой φ*(γ) = (1+γ)ln(1+γ)−γ, Lemmas 2.6–2.7). Наш класс зазор-зависимый, их доказательства не переносятся дословно — нужна своя машина (кандидат: интегрирование (b) с переменным уровнем).

## 7. Лемма 7 (спектральный бюджет цепочки; запрет концентрации зазора)

**Мотивация (негативный опыт).** Цепочка из «честных» cosh-звеньев φ(Δ) = (c₀/κ²)(cosh(κΔ)−1), φ'' = c₀ + κ²φ, со стартом, сосредоточенным в одном звене (x₀ = a·e₁), при κ² = H₁ **нарушает класс**: измеренная λ_max(∇²f(x₀)) = 20350 > H₀c + H₁F₀ = 10243. Причина: спектральное удвоение — звено вносит c₀·cosh(κΔ)·vvᵀ, ‖vvᵀ‖ = 2, а гершгориновский радиус трёхдиагональной цепочки удваивает ещё раз.

**Утверждение (полная версия; все строки Гершгорина выписаны явно).** Пусть

$f(x) \;=\; \sum_{i=1}^{d-1}\varphi(x_{i+1}-x_i) \;+\; \psi(x_d),\qquad \varphi(t)=\tfrac{c_0}{\kappa^2}\big(\cosh(\kappa t)-1\big),\quad \psi(t)=\tfrac{c_\varepsilon}{\kappa^2}\big(\cosh(\kappa t)-1\big).$

Обозначения: Δᵢ := xᵢ₊₁−xᵢ (натяжение i-го звена), gᵢ := φ(Δᵢ) ≥ 0 (звеньевой зазор), g_a := ψ(x_d) ≥ 0 (якорный зазор), F := f(x)−f* = Σᵢ gᵢ + g_a (f* = 0, argmin = {0}); веса wᵢ := φ''(Δᵢ) = c₀·cosh(κΔᵢ) **= c₀ + κ²gᵢ** и w_a := ψ''(x_d) **= cε + κ²g_a** (ключевые тождества: κ²φ(t) = c₀(cosh(κt)−1), κ²ψ(t) = cε(cosh(κt)−1)).

**(a) Структура.** ∇²f(x) = Σᵢ₌₁^{d−1} wᵢ·vᵢvᵢᵀ + w_a·e_de_dᵀ, где vᵢ := eᵢ−e_{i+1}. В частности ∇²f ⪰ 0 (выпуклость), все собственные значения λ ∈ [0, λ_max].

**(b) Все строки Гершгорина** (правило: λ ≤ центр строки + радиус строки; радиус = сумма |внедиагональных| строки; λ ≥ 0 позволяет отбросить левый край круга):

| строка | центр | радиус | итого λ ≤ |
|---|---|---|---|
| 1 | w₁ | w₁ | 2w₁ = 2c₀ + 2κ²g₁ |
| j, 2 ≤ j ≤ d−1 | w_{j−1}+w_j | w_{j−1}+w_j | 2w_{j−1}+2w_j = 4c₀ + 2κ²(g_{j−1}+g_j) |
| d (якорная) | w_{d−1}+w_a | **w_{d−1}** | 2w_{d−1}+w_a = 2c₀ + cε + κ²(2g_{d−1}+g_a) |

**Якорь входит только в центр строки d, не в радиус**: у координаты x_d лишь один внедиагональный сосед (x_{d−1}); вклад ψ'' сидит на диагонали. (Именно здесь ошибался эскиз: радиус строки d брался равным w_{d−1}+w_a.)

**(c) Построчное суммирование.** Каждая строка ≤ 4c₀ + cε + 2κ²·F:
- строка 1: 2c₀+2κ²g₁ ≤ 2c₀+2κ²F ≤ 4c₀+cε+2κ²F (ибо g₁ ≤ F и 2c₀ ≤ 4c₀+cε);
- строка j: g_{j−1}+g_j ≤ Σᵢ gᵢ + g_a = F (все зазоры неотрицательны);
- строка d: 2g_{d−1}+g_a ≤ 2F.

Итого всюду **‖∇²f(x)‖ ≤ 4c₀ + cε + 2κ²·F(x)**.

**(d) Безусловный сертификат.** Если **κ² ≤ H₁/2**, то 2κ²F ≤ H₁F, и f ∈ F(4c₀+cε, H₁) — при любом cε > 0 и без каких-либо ограничений на распределение зазора (в том числе концентрированные старты разрешены).

**(e) Точность порога (факториальность).** Порог H₁/2 — не артефакт оценки: для пробного вектора u = (e₁−e₂)/√2

uᵀ∇²f·u ≥ w₁·(uᵀv₁)² = 2w₁ = 2c₀ + 2κ²g₁,

и если весь зазор сосредоточен в первом звене (g₁ = F, старт a·e₁, a → ∞), требование класса 2c₀+2κ²F ≤ H₀c+H₁F в пределе F → ∞ вынуждает 2κ² ≤ H₁. Тариф «2κ² за единицу сконцентрированного зазора» обязателен (луч Рэлея) и достаточен (строки (b)) — построчная гершгориновская оценка здесь не груба.

**(f) Граничные случаи.** Постоянная часть бюджета: строка 1 — 2c₀ (самая дешёвая); внутренние строки — 4c₀ (худшие, вместе с якорем диктуют H₀c = 4c₀+cε); якорная строка — 2c₀+cε. Зазорная часть (тариф за единицу зазора): первое звено — 2κ²; внутреннее звено — 2κ² (худший случай — пара соседних звеньев несёт весь зазор); последнее звено перед якорем — 2κ²; сам якорный зазор — κ² (самый дешёвый: сидит на диагонали). Граничных послаблений в зазорной части нет — тариф 2κ² един для всех звеньев, различаются только постоянные части.

*Доказательство.* **Шаг 1 (структура).** Прямое дифференцирование: ∂²f/∂x₁² = φ''(Δ₁); ∂²f/∂x_j² = φ''(Δ_{j−1})+φ''(Δ_j) при 2 ≤ j ≤ d−1; ∂²f/∂x_d² = φ''(Δ_{d−1})+ψ''(x_d); ∂²f/∂x_j∂x_{j+1} = −φ''(Δ_j). Разложение (a) — перегруппировка слагаемых: vᵢvᵢᵀ вносит +1 в диагонали (i,i) и (i+1,i+1) и −1 во внедиагонали (i,i+1), (i+1,i). Тождества весов: из κ²φ(t) = c₀(cosh(κt)−1) следует c₀cosh(κt) = c₀+κ²φ(t), т.е. wᵢ = c₀+κ²gᵢ; аналогично w_a = cε+κ²g_a. **Шаг 2 (PSD).** ∇²f — сумма неотрицательно взвешенных PSD-матриц vᵢvᵢᵀ и e_de_dᵀ. **Шаг 3 (строки).** Теорема Гершгорина: |λ−H_jj| ≤ R_j; с λ ≥ 0 имеем λ ≤ H_jj+R_j — это в точности строки таблицы (b). **Шаг 4 (суммирование).** Неотрицательность всех gᵢ, g_a и определение F — неравенства (c). **Шаг 5 (точность).** uᵀ∇²f·u = Σᵢ wᵢ(uᵀvᵢ)² + w_a(uᵀe_d)² ≥ w₁(uᵀv₁)² = 2w₁. ∎

**Протокол исправлений (эскиз → полная версия).** В эскизе было два независимых огрубления, случайно скомпенсировавших друг друга и давших верный, но неоптимальный порог κ² = H₁/4: (α) оценка λ_max ≤ 4·maxᵢ wᵢ вместо построчной (лишний фактор 2: max w проходил через «2×2»); (β) радиус якорной строки w_{d−1}+w_a вместо w_{d−1} (лишняя добавка cε в сертификате: H₀c = 4c₀+2cε). Полный построчный анализ даёт точный порог **κ² ≤ H₁/2** и сертификат **H₀c = 4c₀+cε** при любом cε. Все результаты разделов 9–11 (эталонный кандидат κ² = H₁/4) сохраняют силу — теперь с явным двукратным запасом по H₁-тарифу; для M3 остаётся резерв: κ² = H₁/2 удваивает per-link H₁-эффективность цепочки.

**Численно.** Эталонное семейство (κ² = H₁/4, тариф 2κ² = H₁/2 — ровно половина допуска) при максимально концентрированном старте x₀ = 12·e₁: λ_max(FD-гессиан, степенной метод) = 1210.90; построчный сертификат (c) даёт 4c₀+cε+2κ²F₀ = 1211.24, причём активна строка 1: 2w₁ = 1210.74 — сертификат насыщен с точностью до FD-ошибки (превышение измерения над 2w₁ равно 0.16) ✓; класс-бюджет H₀c+H₁F₀ = 2421.48 — двукратный запас по зазорной части ✓. При x₀/2: 17.5 ≤ 17.93 (сертификат; класс-бюджет 34.9) ✓. При x₀/10: 1.0 ≤ 1.19 ✓.

**Значение для нижней границы.** Класс сам диктует конструкцию цепочки: пер-линковый H₁-тариф обязан быть ≤ 2κ² ≤ H₁, если мы хотим разрешить резистинг-оракулу прятать зазор в одном звене (а сокрытие информации этого требует — см. раздел 10); требование нельзя ослабить — показывает луч Рэлея (e). Потеря фактора 2 (звено входит в гессиан через разность координат: ‖vᵢ‖² = 2) — честная цена вхождения в класс; эталон M1 платит ещё один фактор 2 запаса (κ² = H₁/4), который M3 может вернуть (κ² = H₁/2).

## 8. Правила устройства «плохих долин» (сводка необходимых свойств кандидата)

Кандидат в hard instance для F(H₀,H₁) обязан:

1. **Лежать в классе с явным сертификатом** — по лемме 7: звенья с κ² ≤ H₁/2, H₀c = 4c₀+cε (эталонный кандидат использует κ² = H₁/4 — двукратный запас; при κ² > H₁/2 концентрированные старты запрещены).
2. **Насыщать H₀-кривизну у дна**: λ_max(∇²f(x*)) ≈ H₀c (у дна кривизна обязана падать до H₀ — пусть этот «пол» и будет худшим случаем).
3. **Иметь большое δ = H₁F₀/H₀** — и, по следствию 4, длинную цепочку: √I₂ ≥ arccosh(1+δ).
4. **Прятать информацию (zero-chain свойство)**: старт возбуждает только первые звенья; минимум-якорь — на дальнем конце; каждое звено раскрывается не быстрее, чем за ~√(L/w) шагов (измерено: медианная задержка 106 ≈ √(L_frozen/c₀) = 98.4 на звено).
5. **Твёрдость ≠ слабая выпуклость**: потеря сильной выпуклости сама по себе НЕ создаёт твёрдости (негативный результат 1, раздел 12) — плоское направление просто не возбуждается. Твёрдость создаёт только сокрытие информации.
6. **Измеримая твёрдость**: лучший известный метод (рестартная схема с сертифицированным зазором) платит на кандидате ≥ ~0.6–1.1× от H₁-члена √I₂·log I₃ целевой формулы в H₁-доминированном режиме (раздел 10).
7. **Насыщать H₀-член у дна** (добавлено по разделу 15): дно обязано содержать квадратичную цепочку с линейным членом (структуру Нестерова); лапласианово дно (пружинная цепочка без линейного члена) не задерживает метод — N ≈ 0.02·√I₁ (раздел 15.3, таблица E). ε-зависимость H₀-члена живёт в длине цепочки k₀ ≈ √(H₀R̃₀²/ε), т.е. в размерности (раздел 15.4).
8. **Не создавать паразитных мод** (добавлено по разделу 15): слабый якорь (cε → 0) в глубоком режиме (ε ≲ cε·масштаба²) порождает моду, сидящую целиком в якоре, стоимостью ~ (H₀c/cε)^α·log (α ≈ 0.35 эмпирически, раздел 15.7, таблица E3); якорь соразмерять с целевыми членами.

## 9. Эталонный кандидат: исправленная cosh-цепочка с концентрированным стартом

$$f(x) \;=\; \frac{c_0}{\kappa^2}\Big[\sum_{i=1}^{d-1}\big(\cosh(\kappa(x_{i+1}-x_i))-1\big) \;+\; \frac{c_\varepsilon}{c_0}\big(\cosh(\kappa x_d)-1\big)\Big],\qquad \kappa^2 = H_1/4,$$

- сертификат: **H₀c = 4c₀ + cε, H₁c = H₁** (лемма 7(d): безусловно допустимо вплоть до κ² = H₁/2; здесь κ² = H₁/4 — двукратный запас по H₁-тарифу), f* = 0, argmin = {0};
- параметры экспериментов: d = 40, c₀ = 0.25 (H₀c ≈ 1), H₁ = 2 (κ² = 0.5), cε = 2.5·10⁻⁶, старт x₀ = a·e₁ (весь зазор в первом звене), R̃ = a, F₀ = (c₀/κ²)(cosh(κa)−1);
- класс-чек: см. раздел 7; градиентная лемма и cosh-потолок: см. разделы 2, 5.

## 11. Интерпретация: blueprint для M3

1. **Механизм H₁-члена верхних границ** (подтверждён численно): каждая фаза рестарта стоит ≥ R̃·√(2H₁) (бюджет фазы при Δₛ: Nₛ = R̃√(2(H₀+H₁Δₛ)/Δₛ) ≥ R̃√(2H₁)); фаз S = ⌈log₂(F₀/ε)⌉ ⇒ сумма ≈ √I₂·log I₃. Адаптив ложится на эту кривую (таблица B).
2. **Гипотеза для нижней границы (цель M3)**: резистинг-оракул строит цепочку раздела 9 и отвечает так, что (i) честность = лемма 6(b) попарно (+ полная интерполяционная характеризация — открытая задача раздела 6); (ii) каждое «декадное» снижение зазора требует свежей информации с дальнего конца цепочки: пер-линковая задержка ≥ c·√((H₀+H₁Δ)/w(звена)) с w(звена) ≤ κ²Δ, где κ² допустимо вплоть до H₁/2 (лемма 7(d); эталон консервативен: (H₁/4)Δ) ⇒ прохождение цепочки за декаду стоит ≥ c·√(4/κ²·...) ~ c·√(H₁·Δ/κ²Δ)·√d... — точную форму неравенства задержки вывести в M3 (здесь — численное свидетельство: задержка ≈ √(L/w)).
3. **Размерность**: задержка ~106/звено ⇒ цепочка длины d выдерживает ~106·d итераций сокрытия; dimension freedom (d ≥ c·N, M0) согласован: для нижней границы N ~ √I₂·log I₃ требуется d ≥ N/106 — свободно.
4. **Решающий эксперимент ветки «Разделение»** (риск 1 плана): попробовать метод без фазовой структуры — per-step адаптация шага через локальную кривизну (gap-зависимую). Если он обыграет рестарты на кандидате — лог-форма артефакт; если нет — подтверждение формы. Поставить в M3.

## 12. Негативные результаты (зафиксировать честно)

1. **Слабый якорь ≠ твёрдость.** Свип cε: 0.25 → 2.5·10⁻⁶ при чередующемся старте: frozen 2108 → 1536, адаптив 429 → 371, разделение ~4×, hardRatio ≈ 0.05. Плоское направление (все единицы) не возбуждается стартом и остаётся неоплаченным. Вывод: свойство 5 раздела 8.
2. **Концентрированный старт при κ² = H₁ ломает класс** (лемма 7(e)): измеренное 20350 > 10243. Класс диктует конструкцию: для безусловного сертификата нужно κ² ≤ H₁/2; эталонный кандидат берёт κ² = H₁/4 с двукратным запасом.
3. **Консервативные бюджеты рестартной теории завышены** в ~10–100× (радиус уровня сжимается быстрее R̃): «твёрдость» мерить по целевой формуле T1, а не по теоретической сумме бюджетов фаз.
4. **Кандидат не насыщает H₀-член T1** (раздел 15): в H₀-режиме лучший метод платит ~2% от √I₁, в глубоком — ≤13%; T1 в форме суммы на кандидате недоказуема. Диагноз: лапласианово дно без линейного члена (15.3).
5. **Параллельная блочная композиция даёт max, не сумму** (раздел 15.5, таблица F): один FO-запрос возвращает градиенты обоих блоков одновременно; для суммы нужна серийная связка (гейт или резистинг-оракул) — программа M3.

## 15. Фундаментальная проблема: H₀-член T1 и композиция (sum vs max)

### 15.1 Постановка (по таблице B)

Адаптивная схема на кандидате при малых eps_rel не платит H₀-член: √I₁ на эталоне (a=12) растёт 345 → 1091 → 3449 → 10908 → 34490 (eps_rel 1e-6…1e-10), а измеренный метод (вариант рестартной схемы этой сессии, калибровка ниже) платит 173 → ~300 → 427 → 726. hardRatio ≤ 0.05. **Кандидат не заставляет платить H₀-член: на нём T1 в форме суммы недоказуема — существует метод, платящий ≪ c₁√I₁.**

### 15.2 Три гипотезы и разбор

- **(a) «H₀-член не фундаментален, верхняя граница Лобанова не оптимальна».** Как общее утверждение исключена: при H₁ = 0 класс = L-гладкие, классическая нижняя граница Нестерова Ω(√(H₀R̃²/ε)) обязана присутствовать (наш перенос с явной константой c₁ = √(3/32), численно проверен). Слабая версия (a) остаётся открытой: в совместном режиме (оба инварианта I₁, I₂ велики) сумма может быть не tight — см. 15.6(γ).
- **(b) «Нужен другой экземпляр, заставляющий платить оба члена».** Рабочая гипотеза; ключевое уточнение в 15.5: параллельная блочная композиция даёт только max, для суммы нужна серийная связка.
- **(c) «H₀-член фундаментален, но кандидат его не насыщает».** Подтверждено; диагноз в 15.3.

### 15.3 Диагноз: дно кандидата — «лапласиан», а не «цепочка Нестерова»

У дна гессиан кандидата — пружинная цепочка (c₀ на разностях + слабый якорь cε) **без линейного члена**. У такой структуры нет zero-chain сокрытия: направление на минимум видно из градиента сразу, локализация до ε стоит ~√κ·log(1/eps_rel) с κ ≈ 4c₀/λ_min ≈ 1.3·10³. Численно (таблица E): при стартах с малым зазором (малое δ) метод платит 2–3% от √I₁. **Механизм H₀-члена требует квадратичной цепочки с линейным членом на одном конце (структура Нестерова: трёхдиагональ A + член −e₁ᵀx) — единственной известной честной конструкции, прячущей минимизатор со скоростью одна координата за запрос.**

### 15.4 Бухгалтерия chain-блока: ε-зависимость H₀-члена живёт в размерности

Квадратичная цепочка (радиус R̃₀, длина k₀, рескейл по лемме 1): для span-ограниченных методов с N ≤ k₀ зазор ≥ 3H₀R̃₀²/(32(k₀+1)²). Противник при данных (R̃₀, ε) выбирает k₀ ≈ √(3H₀R̃₀²/(32ε)) — метод обязан сделать ≥ k₀ запросов. НО зафиксированная цепочка после N ≥ 2k₀ + O(k₀·log(1/eps_rel)) разрешается целиком: сложность фиксированной цепочки ~ k₀·polylog, ε-зависимость — только логарифмическая. Численно: цепочка k₀=20 при ε = 1.21e-5 (её floor 3·10⁻³ ≫ ε, т.е. span-ограничение давно снято) решается за 393 итерации — против её «собственного» √(H₀R̃₀²/ε) = 1056. **Вывод: H₀-член переносится на класс только вместе с dimension freedom (k₀ ~ √(1/ε)); в финальном экземпляре цепочка Нестерова обязана иметь длину ~ √(H₀R̃₀²/ε). Dimension freedom — не удобство, а необходимость.**

### 15.5 Композиция: параллельные блоки дают max, НЕ сумму

Блочная конструкция f = f_cosh(x) ⊕ f_nes(y) (ортогональные подпространства, f* = f₁*+f₂*):
- **членство в классе** ✓: гессиан блочно-диагонален, ‖∇²f‖ = max(‖∇²f_cosh‖, ‖∇²f_nes‖); цепочка ровно H₀-гладкая (λ_max = H₀·cos²(π/(4k₀+4)) < H₀ ≤ H₀c + H₁F) — сертификат не меняется;
- **но**: один FO-запрос возвращает полный градиент **обоих** блоков; zero-chain каждого блока продвигается ≤ на 1 координату за запрос — **одновременно** в обоих блоках. Метод с N запросами получает N шагов прогресса в каждом блоке: блоки решаются параллельно, сложность = Θ(max(N₁, N₂)), не сумма.

**Таблица F — параллельная композиция (одна схема, ε = 1.21e-5 во всех строках):**

| k₀ (цепь) | N_cosh | N_nes | N_joint | max | сумма | N_joint/max | N_joint/сумма |
|---|---|---|---|---|---|---|---|
| 20 | 427 | 393 | 471 | 427 | 820 | 1.10 | **0.57** |
| 100 | 427 | 1579 | 1688 | 1579 | 2006 | 1.07 | **0.84** |
| 1000 | 427 | 9156 | 9699 | 9156 | 9583 | 1.06 | 1.01 |

N_joint ≈ max(N_cosh, N_nes) во всех режимах (надбавка 6–10% — от сложения радиусов в фазовых бюджетах); при сопоставимых членах (k₀=20) joint платит 57% суммы: один и тот же метод одновременно гасит оба блока.

**Следствия.**
1. Параллельная композиция + механизм переноса дают честную **max-форму T1′: N ≥ max(c₁√I₁, c₂√I₂·log I₃)** (для span-ограниченных методов; подъём — стандартный мостик; оговорка: члены с раздельными радиусами блоков R̃₀²+R̃₁² = R̃² — при доминировании одного члена разница уходит в константу).
2. **T1 в форме суммы недоказуема параллельной композицией**: нужна серийная связка — блок Нестерова должен быть неинформативен, пока cosh-цепочка не разрешена (либо признать сумму открытой — 15.6(γ)).

### 15.6 Три пути к сумме (программа M3)

- **(α) Честный гейт.** Линейный член квадратичного блока умножить на g(x_d): g ≈ 0 до разрешения хвоста, g(0) = 1. Препятствие (алгебра Шура совместной выпуклости): нужно ψ''(x_d) ≥ (L/4)²·g'(x_d)²·(A⁻¹)₁₁ ≈ (L/4)²·g'², т.е. якорь усиливать до cε ≥ (L/4)²·max g'² + запас — сертификат H₀c растёт, H₁-бюджет сужается; наивная ширина гейта ~√(F/H₀) даёт |g'| ~ √(H₀/F) ≫ H₁F при малых F. Нужен широкий гладкий гейт с пересчётом всех констант — открытая дизайнерская задача.
- **(β) Резистинг-оракул (ядро M3).** Оракул отвечает с замаскированным блоком Нестерова до активации; честность = лемма 6(b) попарно + интерполяционная характеризация (открытая задача раздела 6). Здесь леммы M1 — несущая конструкция.
- **(γ) Принять max-форму.** Тогда зазор между нашей нижней границей (max) и верхней границей Лобанова (sum) — самостоятельный открытый вопрос: либо сумма верна и нужна серийная конструкция, либо сумма не tight и верхнюю границу можно улучшить. Оба исхода — вклад.

### 15.7 Побочный результат: паразитная мода слабого якоря

В глубоком режиме (eps_rel = 1e-12, cε = 2.5e-6) схема платит 45 833 — это НЕ плато и НЕ H₀-член: финальный зазор целиком в якоре (звеньевой 1.6·10⁻¹³, якорный 1.21·10⁻⁹; x_d локализован ровно на масштабе √(2ε/cε) = 0.031). Свип cε при eps_rel 1e-12:

### 15.8 Вердикт по M1

Кандидат раздела 9 — **H₁-term candidate**: валидный носитель H₁-механизма (сокрытие информации, zero-chain динамика, насыщение H₁-члена — таблицы A–C, разделение ×22 с контролем F₀). Вопрос **sum vs max** зафиксирован как центральный для T1 и программы M3.

**Обновление (часть (i) закрыта).** H₀-член max-формы закрыт как **теорема C** (отдельный канвас «Теорема C: гарантированная нижняя граница H₀-члена»): N ≥ √(3/32)·√I₁ − 1, любой H₁ ≥ 0 одновременно, span-ограниченные методы, устойчивость к любой побочной информации (включая f*), точная константа с точными крайними случаями; инвариант-носитель F₀ (лог-цена по радиусу) при согласовании инвариантов.
