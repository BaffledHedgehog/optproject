## 1. Две разные задачи

Основная статья изучает минимум f*Q на компакте Q с доступом к LMO.
Здесь рассматривается безусловная минимизация на ℝᵈ с глобальным f*.
Нижняя граница числа запросов (f,∇f) здесь не является автоматически
нижней границей LMO-сложности статьи. Граничный условный минимум
при H₀=0 не следует отождествлять с достигнутым глобальным минимумом.

## 2. Класс и два радиуса

F(H₀,H₁): выпуклые C²-функции f:ℝᵈ→ℝ с конечным достигнутым
минимумом f* и глобальным условием

$$\|\nabla^2 f(x)\|_{\rm op}\le H_0+H_1(f(x)-f^*).$$

H₀,H₁ — верхние параметры класса, не обязательно минимальные константы
функции. Поэтому H₀-гладкая квадратичная функция лежит в F(H₀,H₁)
при любом H₁≥0. Экземпляр — (d,f,x₀), X*=argmin f, F₀=f(x₀)−f*.
Различаем

$$R_{\rm dist}=\operatorname{dist}(x_0,X^*),\qquad
R_{\rm lev}(x^*)=\sup_{x:f(x)\le f(x_0)}\|x-x^*\|,\quad x^*\in X^*.$$

R и S ниже — сообщённые верхние границы соответственно Rdist и Rlev
для одного выбранного x*. В дистанционной модели дополнительно
требуем ограниченности начального подуровня, но не сообщаем его
радиус. У доказанных ниже конструкций минимум единственен.

Для f(x,y)=(H₀x²+μy²)/2, x₀=(R,0), 0<μ≤H₀:
Rdist=R, F₀=H₀R²/2, Rlev=R√(H₀/μ). Отношение не ограничено
универсальной константой даже при ограниченном подуровне.

У [Лобанова, теорема 5](https://arxiv.org/html/2608.04884v1) R̃ —
радиус **всего начального подуровня**. Дистанционная нижняя граница
ниже не доказывает оптимальности его верхней оценки.

## 3. Точные значения и верхние бюджеты

- Cdist(H₀,H₁,R,Δ): Rdist≤R, F₀≤Δ, начальный подуровень ограничен.
- Clev(H₀,H₁,S,Δ): существует x* с Rlev(x*)≤S и F₀≤Δ.
- Cdist=(H₀,H₁,R;F₀): дистанционная модель с точно заданным F₀.

Нижняя оценка для верхнего бюджета Δ не даёт её для каждого точного
F₀≤Δ. Из сравнения вдоль луча от минимума следует совместимость
точных параметров:

$$F_0\le\Psi(R):=
\begin{cases}(H_0/H_1)(\cosh(\sqrt{H_1}R)-1),&H_1>0,\\
H_0R^2/2,&H_1=0.
\end{cases}$$

Нельзя требовать существования экземпляра для любых независимых
положительных H₀,H₁,R,F₀. Для верхнего бюджета Δ>Ψ(R) ограничение
F₀≤Δ просто неактивно; реализация точного F₀=Δ не требуется.

## 4. Оракул, знания и стоимость

Один локальный запрос в произвольной точке q∈ℝᵈ возвращает точную
пару O_f(q)=(f(q),∇f(q)). Считаются **все** такие запросы.
x₀ известно как часть входа; его функция и градиент не бесплатны.
Выход не обязан совпадать с запрошенной точкой.

Методу известны d,x₀,H₀,H₁,ε и бюджеты выбранного семейства.
Для доказанных нижних границ дополнительно сообщаются точные f* и
F₀: это усиливает метод. Они фиксируются до первого запроса и
не меняются при выборе скрытого базиса. Описание скрытой функции
и её минимизатор не сообщаются.

Детерминированный метод задаёт q₁=φ₁(K),
q_{t+1}=φ_{t+1}(K;(q_i,O_f(q_i))_{i≤t}) и
x̂_N=out(K;история) после ≤N запросов. Span-ограничения нет.

Точная минимизация на отрезке — отдельная более сильная операция,
а не один FO-запрос. У Лобанова различаются внешние итерации с
точной релаксацией и полные запросы при её неточной реализации;
последние требуют дополнительных логарифмических факторов.

## 5. Кванторы нижней границы

Для явно заданного семейства C нужное утверждение:

$$\forall A\quad\forall N<B(K,\varepsilon)\quad
\exists d\ \exists(f,x_0)\in C:
f(\hat x_N)-f^*>\varepsilon.$$

Экземпляр выбирается после метода и бюджета, но все сообщённые
скаляры и ответы должны соответствовать одной финальной функции.
Свобода размерности допускает достаточное конечное d для каждого N.
В подъёме M2 d=3N+4; носитель F₀ добавляет одну координату.
При N=0 не используется невозможное ограничение d≤cN.

В прежней T1 знак был обращён: неуспех требуется при недостаточном N,
а не при N≥B. Медленная работа одного алгоритма не доказывает
нижней границы для всех FO-методов.

## 6. Доказанное и открытое

**Доказано:** классический H₀-член для дистанционной модели. Для
каждого N≥0 существует согласованное значение
F₀,N=3H₀R²/[4(4N+7)], при котором любой детерминированный метод
с ≤N запросами имеет трудный экземпляр с

$$f(\hat x_N)-f^*\ge\frac{3H_0R^2}{4(2N+3)(4N+7)}
\ge\frac{3H_0R^2}{32(N+2)^2}.$$

Подуровень ограничен; точные f*=0,F₀,N сообщены. Полное доказательство
с квадратичной добавкой на дополнении — в M2. Для верхнего бюджета
Δ нужен Δ≥F₀,N. Произвольный точный F₀ — лишь в диапазоне теоремы C.

**Доказано:** одномерная бисекция с наблюдаемым сертификатом без H₁.

**Открыто:** информационная H₁-нижняя граница для всех детерминированных
FO-методов на согласованном режиме H₀>0. При H₀=0 и достигнутом
глобальном минимуме f постоянна (M1); нет нетривиального подсемейства
с ограниченным подуровнем. Старую подцель T1b использовать нельзя.

**Открыто:** совпадение оценок в Clev с радиусом S. Дистанционная
цепочка не закрывает эту задачу автоматически.

## 7. Сумма и максимум

Для A,B≥0: max(A,B)≤A+B≤2max(A,B). Если на **одном и том же**
параметризованном классе Comp≥c₁A и Comp≥c₂B, то
Comp≥min(c₁,c₂)(A+B)/2. Для каждого метода выбирается экземпляр
труднейшей ветви. Последовательный гейт для Ω(A+B) не требуется.
Разные точные F₀, радиусы или модели оракула так объединять нельзя.
Точные константы и особая двухстадийная структура — более сильные
вопросы. Сейчас отсутствует прежде всего сама H₁-ветвь.

## 8. Следующий шаг и литература

Фраза «ниша свободна» отозвана. Нижние оценки для ограниченных
правил GD или параметрически слепых методов в иных моделях
не заменяют универсальной границы здесь. Счётчики цитирований
из старого M0 не используются как доказательство приоритета.

Сначала выбрать одну радиусную модель и режим F₀. Затем строить
H₁-сопротивляющийся оракул с глобальным членством и заданным
радиусом. Достаточная интерполяционная характеристика могла бы
помочь, но попарное необходимое неравенство M1 ею не является.
