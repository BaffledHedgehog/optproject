Статья: Observable Certificates and Exact Termination in Backtracking
Frank–Wolfe. Авторы: Yaroslav P. Lyakhov и Stepan A. Suvorov.

Что отправить Гасникову

paper.pdf — текущая публикационная версия, 29 страниц.
COVER_LETTER_RU.txt — готовый текст письма для копирования.
REVIEW_GUIDE_RU.txt — краткий путеводитель по основному доказательству.
for_gasnikov_v2.zip — эти три файла одним архивом.

Основной результат находится на страницах 10–13: Theorem 5.1 и
Corollaries 5.2–5.3. Экспертное человеческое чтение ещё ожидается;
его результат не подменяется программными проверками.

Файлы для подачи

arxiv_source_v2.zip — чистые LaTeX-исходники, используемые таблицы и рисунки.
Главный article.tex лежит в корне архива. В архив не входят собранный
article.pdf, Python-скрипты, переписка, история восстановления или
служебные файлы сборки. Компилятор — PDFLaTeX.

ARXIV_METADATA.txt — название, авторы, abstract и comments для копирования.
submission_metadata.json — те же сведения в машинном формате.
Рекомендуемая основная категория: math.OC. Дополнительные категории
не выбраны; DOI и journal reference не указаны.

Для самостоятельной подачи:
1. Открыть новую submission в своём аккаунте arXiv.
2. Загрузить arxiv_source_v2.zip; выбрать article.tex и PDFLaTeX.
3. Проверить полученный PDF: ожидаются 29 страниц, 3 рисунка и 6 таблиц.
4. Скопировать метаданные и выбрать лицензию распространения.
5. Использовать фактические сведения авторов и аккаунта. Институциональная
   принадлежность и адреса не выдумывались. При необходимости пройти
   запрошенный самим arXiv endorsement.

Рекомендация перед окончательной отправкой — дождаться экспертного
ответа на основное доказательство и учесть замечания. Пакет подготовлен
локально; отправка в arXiv или сообщений другим людям не выполнялась.

Код и данные

reproducibility_v2.zip — отдельный пакет воспроизводимости. Он не является
основным TeX-файлом для загрузки в arXiv. В нём сохранены входные данные,
метаданные и замороженные артефакты прежних baseline-экспериментов, новый
строгий 324-run endpoint-протокол, 54 рациональных примера, тесты и
ограниченные Lean-проверки. Первичная нестрогая попытка кэширования
исключена из публикационной таблицы и этого пакета.

В основной статье используются только новые проверенные endpoint-числа.
PROVENANCE_AND_NUMERICAL_NOTE.txt отдельно сохраняет историю редакции
и расхождение с прежним авторским PDF. Эта заметка не включена в статью
или arxiv_source_v2.zip. Раскрытие существенного использования генеративных
инструментов и границы малых Lean-проверок сохранены в научном тексте.

Пересборка из полного дерева репозитория или reproducibility_v2.zip:

    cd PART3/Submission/2026-11-01
    python -m pip install -r requirements.txt
    python prepare_submission.py --build
    python submission_checks.py --tests

Для повторного выпуска после замечаний:

    python prepare_submission.py --package --verify --tag v3

Сначала нужно выполнить --build после правок. Уже созданные ZIP не
перезаписываются; новый tag сохраняет предыдущий проверенный выпуск.
--verify распаковывает пакеты в новые каталоги, компилирует чистые
arXiv-исходники и полный пакет, проверяет численные свидетельства и тесты.

submission_validation_v2.json содержит результат проверки архивов;
package_manifest_v2.json — контрольные суммы. Для сборки нужен PDFLaTeX
в PATH или параметр --engine с путём к нему.
