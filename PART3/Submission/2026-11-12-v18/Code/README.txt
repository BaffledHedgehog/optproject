Запуск кода v18

Команды ниже выполняются из каталога выпуска 2026-11-12-v18.
Для численных расчётов достаточно Python 3 и стандартной библиотеки.
Для построения графиков дополнительно нужен matplotlib.

1. Эксперимент с большим нормальным компонентом градиента:

   python Code/benchmark_boundary.py --no-plots

   Результаты: Evidence/boundary_benchmark.csv,
   Evidence/boundary_benchmark.json и Evidence/boundary_trace.csv.

   Чтобы также построить графики:

   python -m pip install matplotlib
   python Code/benchmark_boundary.py

   Графики сохраняются в Paper/figures в форматах PDF и PNG.

2. Проверка направленных оценок:

   python Code/check_directional.py

   Результат проверки: Evidence/directional_checks.json.

Протокол эксперимента детерминирован: функция, начальная точка,
параметры, выбор линейного оракула при равенстве значений и точность
остановки фиксированы. Случайные данные не используются.

Сравнивается фиксированный Algorithm 1 Выгузова и Стонякина с
квадратичным backtracking. Адаптивный Algorithm 2 в это сравнение
не входит. Оба метода используют одинаковый накопленный сертификат.

Счётчики включают начальное вычисление функции, все принятые и
отклонённые пробы, а также заключительную проверку градиента и
линейного оракула. При N принятых шагах выполняется N+1 вызовов
градиента и N+1 вызовов линейного оракула. Фиксированный метод
вычисляет функцию N+1 раз; backtracking вычисляет её 1+N+R раз,
где R есть число отклонённых проб.

Истинное значение минимума не используется решателем для выбора
шага или остановки. В эксперименте оно используется только для
проверки итоговой ошибки после остановки.
