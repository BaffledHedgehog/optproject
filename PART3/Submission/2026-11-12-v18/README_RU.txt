Основная постановка

Функция выпукла и дважды непрерывно дифференцируема в окрестности
непустого компактного выпуклого множества Q. Условие гладкости:

  ||∇²f(x)|| ≤ L0 + L1||∇f(x)||,  x ∈ Q.

Это исходная градиентная модель Выгузова и Стонякина. Неизвестное
минимальное значение не входит ни в условие гладкости, ни в шаг,
ни в проверку остановки. Стремление нормы градиента к нулю не требуется.
Символы f(x) − f(x*) и ||∇f(x)|| записываются прямо, без новых сокращений.

Что доказано

1. Для полного зазора G(x) сохраняется нижняя граница
   ℓ = max_j {f(x_j) − G(x_j)}. Остановка f(x_k) − ℓ ≤ ε гарантирует
   f(x_k) − f(x*) ≤ ε. Квадратичный подбор шага и весь метод
   завершаются за конечное число запросов; подсчитаны все отклонённые
   вычисления функции и заключительная проверка остановки.
2. Для оракула с известной абсолютной направленной ошибкой доказан
   конечный перенос точности между шагами. Проверка остановки идёт
   раньше требования относительной точности.
3. На Q0 × [0,1] добавление A*y к φ(z) не меняет ни одной операции
   точного метода, начатого на y=0, при общем правиле разрешения
   неоднозначности линейного оракула. Норма градиента в минимуме ≥ A.
4. Для exp(x)+A*y на [-1,1] × [0,1], старта (a,0), 0<a<1,
   ε<1−exp(−1), фиксированное правило Algorithm 1 Выгузова–Стонякина
   с L0=L1=1 требует не менее ceil(a*exp(1−a)*A) шагов.
   Подбор шага имеет конечное время остановки, не зависящее от A.

Полный зазор и обычный квадратичный подбор шага являются известными
механизмами. Сравнение относится к указанному фиксированному Algorithm 1;
адаптивный Algorithm 2 той работы здесь не сравнивается.

Воспроизводимый опыт

Старт (0.7,0), ε=10^−6, начальная память кривизны 1.
Оба метода используют один и тот же накопленный сертификат остановки.

A          Фиксированное правило          Подбор шага
0          11                            2
1          14                            2
10         66                            2
100        610                           2
1000       6045                          2

Каждый запуск подбора шага: 5 вычислений функции, 3 градиента,
3 полных линейных минимизации. В 5 вызовов функции входят 2 отклонённые
пробы. Код, полный журнал и протокол находятся в Code/ и Evidence/.
Случайности и подбора параметров по этим результатам нет.

Восемь дополнительных фиксированных проверок направленного оракула
включают старт непосредственно в граничном минимуме с ненулевым
градиентом. Все восемь проверок пройдены. При таком старте метод
останавливается без шагов и с одним вычислением функции, хотя
относительное условие точности оракула ещё не выполнено.

Воспроизведение из каталога этого выпуска

  python Code/benchmark_boundary.py --output reproduced --plots reproduced/figures
  python Code/check_directional.py
  python build_papers.py

Для численных вычислений достаточно стандартной библиотеки Python 3.
Для графиков нужен matplotlib; флаг --no-plots отключает их построение.
Скрипт направленных проверок перезаписывает свой результат в Evidence/.
Сборка PDF не запускает эксперименты. Нужны pdfLaTeX для EN, XeLaTeX
для RU, стандартные пакеты LaTeX, Liberation Serif/Sans и DejaVu Sans Mono.

Evidence/independent_review.txt. Готовые PDF просмотрены постранично.
