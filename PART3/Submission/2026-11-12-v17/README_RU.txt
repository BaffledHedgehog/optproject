V17: КОМПАКТНАЯ СТАТЬЯ И ТОЧНАЯ ОЦЕНКА С ДИАМЕТРОМ
12 ноября 2026

paper.pdf: английская статья, 23 страницы.
paper_ru.pdf: русская статья, 23 страницы.
guide_professor.txt: краткий разбор, пример и маршрут чтения.

В основной статье оставлены полные доказательства центральных результатов.
Повторные радиальные выводы объединены. Расширенные тексты и сопроводительные
записи v16 предоставляются отдельно в архиве extended_sources_and_records_v16.zip.
Этот архив не входит в публичный репозиторий. Размер шрифта 11 pt не уменьшен.
Длинные тире, повторные оговорки и канцелярские формулировки убраны из
обеих новых статей. Исторические записи сохраняются без редактирования.

Новый результат использует полный зазор, норму градиента и диаметр.
Для m=1, H0=4, H1=0, g=1, P=2, D=3/5 граница уменьшается с 23/16 до 463/400.
Доказаны точность при диаметре ровно D и условие допустимости точных
наблюдений g<=P*D. Точность относится к классу меняющихся областей.

СТРУКТУРА

Paper/: исходники английской статьи; Paper/ru/: русской.
Code/certified_envelopes/: API v16 и неизменённые прежние записи.
Code/certified_diameter/: новый API и первый фиксированный протокол из 10 вызовов.
Evidence/: текущие проверки сборки, вёрстки и результата с диаметром;
отдельный фиксированный скалярный сертификат для чисел в таблице статьи.
PUBLICATION_SCOPE.txt: состав публичного комплекта и отдельного архива.
arxiv_source_v17.zip, arxiv_source_ru_v17.zip: исходники текущих статей и рисунок.
reading_packet_v17.zip: оба PDF, краткий разбор, инструкция и состав выпуска.

СБОРКА

Нужны Python 3.10+, TeX Live с pdflatex, xelatex, amsmath, amsthm, geometry,
hyperref, lmodern, fontspec и polyglossia. Для русского текста нужны
Liberation Serif/Sans и DejaVu Sans Mono; при их отсутствии используются
Times New Roman, Arial и Consolas.

  python build_papers.py

Скрипт делает три прохода каждого движка. Он не запускает научные
проверки и не меняет сохранённые экспериментальные записи. Новые PDF
появятся в Paper/paper.pdf и Paper/ru/paper_ru.pdf. Файлы в корне
выпуска являются проверенной опубликованной сборкой.

Источник рисунка: draw_diameter_geometry.py. Он создаёт векторный PDF
в figures/; для новой сборки его нужно скопировать в Paper/figures/
и Paper/ru/figures/. Рисунок иллюстрирует аналитические конструкции. Для его перерисовки
нужен matplotlib; готовый PDF уже включён в исходники.

КОД И ПРОВЕРКИ

Нужны Python 3.10+ и mpmath==1.3.0. Инструкции и точный результат находятся
в Code/certified_diameter/USAGE_AND_RESULTS.txt и EVIDENCE_RU.txt.
Новый протокол: 10 вызовов, 7 сертификатов, 3 ожидаемых отказа, 184 проверки.
Все исходы сохранены. Для независимого воспроизведения из корня выпуска
скопируйте полный зафиксированный пакет в новую папку. Команды для Linux/macOS:

  python3 -c "import shutil; shutil.copytree('Code/certified_diameter/runs/run_001/source_snapshot/certified_diameter', 'reproduce_v17/certified_diameter')"
  python3 -m venv reproduce_v17/venv
  reproduce_v17/venv/bin/python -m pip install -r reproduce_v17/certified_diameter/requirements.txt
  reproduce_v17/venv/bin/python reproduce_v17/certified_diameter/run_protocol.py

В Windows используйте python вместо python3 и путь
reproduce_v17/venv/Scripts/python.exe вместо reproduce_v17/venv/bin/python.

Папка reproduce_v17/certified_diameter до копирования не должна существовать.
Снимок содержит все 20 зафиксированных файлов, FREEZE.json и исходный review.
Скрипт проверяет их хеши до импорта API, затем создаёт собственный runs/run_001
в новой копии. Исходные записи не удаляются и не перезаписываются.
Новая запись появится в reproduce_v17/certified_diameter/runs/run_001/result.json.
Ожидаются PASS, 10 вызовов и 184 проверки. Хеш всего JSON может отличаться:
он содержит время, локальные пути и сведения об окружении.
Это инструкция для будущего независимого запуска; при подготовке выпуска
протокол повторно не исполнялся.

Записи прежних скалярных API находятся в Code/certified_envelopes.
Редакция не добавляет новых запусков оптимизации или сравнений времени.
Состав публичного выпуска и отдельного архива указан в
PUBLICATION_SCOPE.txt. Пакеты скалярных сертификатов и их фиксированные
проверки включены полностью. Публичный комплект позволяет пересобрать текущие
статьи и воспроизвести эти скалярные проверки. Полное повторение всех прежних
оптимизационных экспериментов не входит в его заявленный состав.
Статус: исследовательская рукопись; внешняя подача не выполнялась.
