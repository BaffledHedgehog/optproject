1. КАКУЮ ЗАДАЧУ РЕШАЕТ РАБОТА

Метод Франка-Вульфа умеет вычислять полный зазор G. Для выпуклой функции
G ограничивает ошибку до глобального минимума. Для невыпуклой функции
такого вывода обычно нет. Здесь найдены точные границы ошибки для класса
с известными условиями регулярности и кривизны.

Пишем delta=f(x)-f(x*), P=||grad f(x)||. Предполагаем, что на всей области Q

  <grad f(z)-grad f(x*),z-x*> >= m||z-x*||^2,
  ||Hessian f(z)|| <= H0+H1*delta(z),
  m>0, H0>=m, H1>=0.

Первая строка называется сдвинутым условием секущей, или RSI.
Минимум x* может лежать на границе, и grad f(x*) может быть ненулевым.
Норма гессиана во второй строке не возводится в квадрат.
Константы должны быть обоснованы для всей нужной области.
Успешный подбор шага сам по себе их не подтверждает.

2. ЧТО ДАЮТ СОВМЕСТНЫЕ НАБЛЮДЕНИЯ

Отдельно можно получить границу E(P) по норме и B(g) по полному зазору.
Их минимум не всегда использует всю информацию. Совместная граница J(g,P)
требует, чтобы один и тот же худший пример согласовывался с обоими числами.

При m=H0=P=1, H1=0, g=1/2 обе отдельные оценки равны 1/2,
а совместная равна 3/8. Это точные значения, не округлённый эксперимент.

Все оценки сводятся к одному радиальному профилю V(g,rho), где rho
обозначает квадрат расстояния до минимума. Общая лемма и полное
доказательство находятся в разделе 3. Это позволило убрать повторные
выводы из прежних разделов и приложений.

3. НОВОЕ В V17: ИСПОЛЬЗОВАНИЕ ДИАМЕТРА

Если известен диаметр D или его верхняя граница, положим

  h=min(g,P^2/m,P*D),
  rho_min=h^2/P^2,
  rho_max=min(h/m,D^2).

Точная граница J_D(g,P) равна максимуму V(h,rho) на этом отрезке.
При нулевых g или P результат равен нулю, деление на P не выполняется.

Для m=1, H0=4, H1=0, g=1, P=2, D=3/5:

  без диаметра: J=23/16=1.4375;
  с диаметром: J_D=463/400=1.1575.

Граница уменьшается примерно на 19.5%. Сами наблюдения могут быть точными:
1<2*(3/5). Для заданных положительных точных g,P,D допустимость равносильна
g<=P*D. Если g и P задают верхние границы, значение g>P*D допустимо:
формула учитывает более сильную границу P*D.

Оценка точна даже при диаметре ровно D. В доказательстве строятся
треугольники с двумя сторонами длины D и гладкие почти экстремальные
функции на них. Рисунок 1 показывает обе конструкции. Допустимая область
может меняться; точность для каждого заранее выбранного многогранника
не утверждается.

Норма и диаметр без зазора тоже дают точную границу E_D(P).
В том же примере она равна 543/400. При H1=0 и P>=mD она аффинна по P:

  E_D(P)=P*D+beta*D^2,
  beta=(H0^2-2*m*H0-m^2)/(4*H0).

4. КОГДА НЕ НУЖЕН ПЕРЕБОР РАДИУСОВ

При H1>0 явное выражение S(g) точно определяет режим B(g)=g:
это происходит тогда и только тогда, когда S(g)<=0.
Для проверки S нужны арифметика и квадратный корень.
В частном случае H0=m порог равен (2+sqrt(6))*m/H1.

Если S(h)<=0, максимум совместной границы находится в левом конце
отрезка. Достаточно одного скалярного уравнения переключения.
Есть также алгебраическая верхняя оценка без решения уравнения.
Вне этого режима применяется гарантированная конечная сетка.
Профиль не всегда вогнут; общая схема не предполагает вогнутость
или единственность локального максимума.

5. КАК СЕРТИФИКАТ ОСТАНАВЛИВАЕТ АЛГОРИТМ

Если C>=delta(x), то f(x)-C<=f(x*). Сохраняем наибольшую полученную
нижнюю границу ell и проверяем U=f(x)-ell<=epsilon.
Совместный сертификат можно сочетать с другими верными границами.
При известном D теорема использует более точную калибровку B_D.

Для неточного направления сначала проверяется остановка, затем точность
для надёжного шага. Если точности не хватает, допустимая ошибка делится
пополам. Достигнутая точность переносится в следующую точку.

При N принятых шагах и R уточнениях всего T=N+1+R запросов.
Последний запрос и неудачные уточнения входят в счёт. Пробы функции,
скалярные вычисления сертификата и просмотр активных атомов учитываются
отдельно. Для AFW оракул выбирает именно атом, а просмотр активного
множества выполняется после успешной проверки точности FW.

Значения функции в теореме точны. Случайная реализация дополнительно
требует свежих направленных наблюдений, известных границ дисперсии
и конечного явно заданного множества атомов.

6. ЧТО ПРОВЕРЕНО КОДОМ

Новый фиксированный протокол диаметра выполнен один раз: 10 вызовов,
7 сертификатов, 3 ожидаемых отказа, 184 проверки контрольного скрипта.
Выполнены 113 учитываемых скалярных вычислений и 61 шаг бисекции.
Параметры и исходники зафиксированы до запуска; первый результат сохранён.
Новых оптимизационных траекторий, решений ЛП и случайных выборок нет.

Прежний API v16 имеет отдельную запись 16 вызовов и 238 проверок.
Прежний v15 имеет отдельную запись 26 вызовов и 503 проверки.
Результаты не складываются в число независимых экспериментов.
Оба пакета скалярных сертификатов и их фиксированные записи входят в
публичный выпуск. Фиксированный эталон для чисел в таблице статьи находится
в Evidence/joint_reference_result.json.

Из каталога Code можно вычислить точный пример:

  from certified_diameter import Model, certify_joint_diameter
  model=Model(m="1", H0="4", H1="0")
  result=certify_joint_diameter(g="1", P="2", D="3/5", model=model)
  print(result.status, result.envelope_upper)

Ожидаемые значения: certified и 463/400. Нужны Python 3.10+ и mpmath==1.3.0.
Строки задают точные рациональные входы; обычные float отклоняются.
Только верхняя граница включения ограничивает реальную ошибку задачи.
Нижняя граница относится к математической огибающей.
API проверяет вычисления, но не предпосылки RSI на исходной функции.
