# Расширенный эксперимент PART3

Параметры: seed 0–9, максимум 1000 обновлений, остановка по накопленному сертификату U ≤ 1e-05.

Все задачи совпадают для методов одного seed. H_nonnegative дополнительно знает нижнюю границу 0; остальные варианты H её не используют. H₀,H₁ известны аналитически. Эталонные решения не передаются оптимизаторам. Гиперпараметры baseline фиксированы, подбор на тестовых задачах не выполнялся.

Медианы включают запуски, исчерпавшие бюджет. Столбец успехов обязателен: 1000 итераций не означает достижение точности. Ошибка — верхняя граница f(x)−f*, вычисленная по независимой нижней оценке эталона. Для cosh эталон точный; для логистической регрессии ширина эталонного интервала записана в manifest.json.

Время — один запуск каждого метода на задаче, медиана и IQR по seed, включая ведение журнала и сертификата; это предварительное измерение, не микробенчмарк. Вызовы f и ∇f считаются раздельно; принятые значения при поиске шага повторно используются. Производные внутри поиска секущими считаются градиентами. Построение задачи и эталона во время метода не входит.

## Интерпретация

Сравнивать качество следует одновременно с сертификатом и бюджетом оракулов. Успехов может быть мало даже при маленькой фактической ошибке: сертификат консервативен. breast_cancer — контроль H₁=0 на реальных данных; он не проверяет выгоду обобщённой гладкости. Активные cosh-задачи специально сконструированы с известным ККТ-решением и не заменяют внешнюю проверку на естественных задачах с H₁>0.

В aggregate.csv также есть парный bootstrap-интервал для медианы отношения конечных ошибок к H_memory. Это описательная статистика при данном бюджете и правиле остановки; она не является поправленным тестом множественных гипотез. Нулевые ошибки в знаменателе ограничены снизу 1e-15. Десять seed дают лишь предварительную оценку устойчивости; для статьи нужны дополнительные семейства задач и повторные замеры времени.
