# Расширенный эксперимент PART3

Параметры: seed 0–9, максимум 1000 обновлений, остановка по накопленному сертификату U ≤ 1e-05.

Все задачи совпадают для методов одного seed. H_nonnegative дополнительно знает нижнюю границу 0; остальные варианты H её не используют. Явные H-шаги получают аналитические H₀,H₁; adaptive_certificate их не читает и использует диаметр 2R. Эталонные решения не передаются оптимизаторам. Гиперпараметры baseline фиксированы, подбор на тестовых задачах не выполнялся.

Медианы включают запуски, исчерпавшие бюджет. Столбец успехов обязателен: 1000 итераций не означает достижение точности. Ошибка — верхняя граница f(x)−f*, вычисленная по независимой нижней оценке эталона. Для cosh эталон точный; для логистической и пуассоновской регрессии ширина интервала записана в manifest.json.

Время — один запуск каждого метода на задаче, медиана и IQR по seed, включая ведение журнала и сертификата; это предварительное измерение, не микробенчмарк. Вызовы f и ∇f считаются раздельно; принятые значения при поиске шага повторно используются. Производные внутри поиска секущими считаются градиентами. Построение задачи и эталона во время метода не входит.

## Интерпретация

Сравнивать качество следует одновременно с сертификатом и бюджетом оракулов. Успехов может быть мало даже при маленькой фактической ошибке: сертификат консервативен. breast_cancer — контроль H₁=0 на реальных данных; он не проверяет выгоду обобщённой гладкости. bike_poisson — регрессия реальных суточных счётчиков UCI с аналитическими H₀,H₁>0. В ней seed меняет только начальную вершину; обучающая задача общая. Это оптимизационный опыт, а не оценка качества прогноза. Активные cosh-задачи специально сконструированы с известным ККТ-решением.

В aggregate.csv также есть парный bootstrap-интервал для медианы отношения конечных ошибок к control_method (H_memory, если он включён). Это описательная статистика при данном бюджете и правиле остановки; она не является поправленным тестом множественных гипотез. Нулевые ошибки в знаменателе ограничены снизу 1e-15. Десять seed дают лишь предварительную оценку устойчивости; для статьи нужны дополнительные семейства задач и повторные замеры времени.
