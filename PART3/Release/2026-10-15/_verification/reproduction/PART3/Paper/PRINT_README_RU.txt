Материалы для печати и подготовки препринта
Ярослав Ляхов Павлович; Суворов Степан
15 октября 2026

Основная статья: article.pdf. Язык — английский, формат A4, имена на
титуле — Yaroslav P. Lyakhov и Stepan Suvorov. Аффилиации и контактный
адрес не были предоставлены и не выдуманы. Расширенный технический
отчёт с дополнительными выводами и историей экспериментов —
technical_report.pdf (в рабочем каталоге Paper/manuscript.pdf).

Содержание научного результата

Работа анализирует существующий FW с обычным квадратичным backtracking,
а не вводит новый алгоритм. При ограничении гессиана через H0+H1(f-f*)
доказана остановка по вычислимому сертификату с раздельной ценой
H0/epsilon и H1 log(1/epsilon), явной ценой начальной кривизны и учётом
всех проб функции. Приведены AFW-расширение и логарифмическая гарантия
при дополнительном геометрическом неравенстве. Все основные
доказательства включены в статью. Первый или оптимальный метод,
общий выигрыш по времени и гарантированное принятие arXiv не заявляются.

В основном сравнении 756 записей семи методов на 108 прежних условиях
Seoul/Metro: 648 сохранённых запусков и 108 дополнительных AC-FW.
Основной бюджет — 1000 вызовов функции. Неудачные запуски сохранены.
Контроль начальной точки и отдельное исследование сертификатов
показывают ограничения интерпретации наблюдаемого выигрыша.
Повторные траектории, масштабы и профили не названы независимыми задачами.

Сборка и воспроизведение

После извлечения reproducibility.zip из его корня:

  python -m pip install -r PART3/requirements-paper.txt

Нужен установленный PDFLaTeX из TeX Live либо MiKTeX. Для численных
команд задайте OPENBLAS_NUM_THREADS=1, OMP_NUM_THREADS=1,
MKL_NUM_THREADS=1. В PowerShell это $env:ИМЯ='1'. Затем:

  python -m unittest discover -s PART3/Work -p "test_*.py"
  python PART3/Work/validate_results.py
  python PART3/Paper/prepare_article_evidence.py
  python PART3/Paper/build_papers.py
  python PART3/Paper/validate_article.py

Если pdflatex отсутствует в PATH, передайте build_papers.py параметр
--engine с полным путём. Генератор таблиц записывает claim_ledger.csv:
для чисел в таблицах указаны архив, выборка и значение. Перезапуск
генератора графика может менять PDF-метаданные даты при том же рисунке.

Дополнительный AC-FW-опыт из архивного исходника:

  python PART3/Work/count_comparator_results/source/count_comparator.py --output PART3/Work/reproduced_count_comparator
  python PART3/Work/validate_results.py PART3/Work/reproduced_count_comparator

Каталог нового опыта должен быть пустым. Прежние архивы сохраняются.
Для остальных опытов команды и описания находятся в PART3/README.md;
манифесты содержат исходный протокол и версии кода.

Подготовка подачи в arXiv

Источник для PDFLaTeX — article.tex в корне arxiv_source.zip. Архив
содержит только используемые TeX-файлы и рисунок; конечный PDF, логи,
код экспериментов и неиспользуемые картинки в него не добавлены.
Локальная изолированная сборка проверяется отдельно; это не запуск
на сервере arXiv. На сайте потребуется просмотреть полученный PDF.
Официальные требования к TeX:
https://info.arxiv.org/help/submit_tex.html

Основная предлагаемая категория — math.OC. Внешняя отправка не
выполнена. Учётную запись, при необходимости endorsement, лицензию
распространения и окончательные авторские метаданные выбирают авторы:
https://info.arxiv.org/help/submit/index.html
https://info.arxiv.org/help/endorsement.html
https://info.arxiv.org/help/license/index.html

В статье раскрыто существенное использование Codex для исследования,
доказательств, программ, экспериментов и текста. Это соответствует
официальной политике arXiv о генеративных инструментах:
https://info.arxiv.org/help/moderation/index.html#policy-for-authors-use-of-generative-ai-language-tools
Перед внешней подачей обоим авторам необходимо проверить научные
утверждения, ссылки и фактическое описание своей работы. Подготовленный
пакет не подтверждает такую персональную проверку и не заменяет рецензию.

Пределы имеющихся проверок

Проходят 58 тестов и валидация 11 экспериментальных архивов, отдельно
повторяется точный рациональный аудит. Конечный перебор и внутренний
AI-аудит не доказывают универсальную теорему сами по себе: основания —
аналитические доказательства в тексте. Независимой внешней экспертизы
не проводилось. Эталонные интервалы численные, без направленного
округления. Политика источников и граница вклада описаны в
Work/publication_literature.json и Work/novelty_audit.md.

Исходные UCI-данные сохраняют атрибуцию и CC BY 4.0 в Data/*/source.json.
Проектная лицензия на собственный код автоматически не назначалась.
