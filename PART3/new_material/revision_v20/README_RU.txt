Редакция v20 от 14 ноября 2026 года
«Метод Франк–Вульф при гладкости через зазор»
Авторы: Ярослав П. Ляхов и Степан А. Суворов.

Основные файлы
  paper_en_v20.pdf / paper_ru_v20.pdf — статья на двух языках.
  REVIEW_RESPONSE_v20.txt — ответ на все пункты проверки v19.
  guide_professor_v20.txt — краткое объяснение результата и его границ.
  Paper/ — редактируемые LaTeX-исходники и рисунки.
  Code/ — полный код исходных и новых опытов и проверок.
  Evidence/ — данные, протоколы, траектории, счётчики и отчёты.
  arxiv_source_v20.zip / arxiv_source_ru_v20.zip — отдельные архивы исходников.
  reading_packet_v20.zip — полный комплект, включая данные (около 45 МБ).
  SHA256SUMS.json — контрольные суммы файлов полного комплекта.

Это доработанная рукопись для обсуждения с научным руководителем и подготовки
журнальной подачи. Внешнее рецензирование, принятие журналом и размещение на arXiv
не выполнялись. Выбор конкретного журнала и его оформление в этот комплект
не входят. Новые доказательства нужно прочитать авторам перед подачей.

Что подтверждено
Исходные 24 запуска воспроизведены. Итоговые числа совпадают; максимальное
абсолютное расхождение элементов старой траектории 9.1e-13. Прежние скрипты
benchmark_gap.py и check_algebra.py сохранены без изменений из архива v19.
Пройдены 13 символьных тождеств и 8 новых тестов реализации.
Новый протокол: 18 задач, 54 конфигурации старта, 8 правил шага = 432 запуска.
423 запуска достигли сертификата 1e-4; 9 запусков Open-loop исчерпали бюджет
20 000 попыток. Они сохранены во всех сводках. Это не 432 независимых задачи.
Проверены 340 433 записанные точки. Все 432 конфигурации дополнительно
воспроизведены из сохранённых входных данных; время не сравнивается на равенство.
Символьные и численные проверки не заменяют математические доказательства.

Установка
Проверено: Python 3.13.5, Windows 10, версии библиотек в requirements.txt.
Из этой папки:
  python -m pip install -r requirements.txt

Быстрая проверка имеющегося комплекта:
  python verify_release.py
Полная повторная проверка конечных результатов, статусов и счётчиков:
  python verify_release.py --replay
Вторая команда повторяет 432 конфигурации без сохранения новых траекторий.
Она читает готовые данные A,y; эталонные оптимумы в solve не передаются.
В Evidence/checks записывается новый отчёт проверки.

Полное воспроизведение опытов с новыми траекториями (PowerShell):
  $env:OPENBLAS_NUM_THREADS = '1'
  $env:OMP_NUM_THREADS = '1'
  python Code/benchmark_gap.py --output Evidence/reproduced_v19 --plots Evidence/reproduced_v19/figures
  python Code/benchmark_multidim.py --output Evidence/reproduced_multidim
Результаты в указанном --output перезаписываются при повторном запуске.
Публикационные результаты в Evidence/v19 и Evidence/multidim сохраняются.
Основной опыт включает три повторения для времени; их медиана сохраняется.
Каждое повторение проверяется на совпадение результата и счётчиков.
Это локальные измерения малых синтетических задач, а не универсальный рейтинг.

Таблицы и рисунки из сохранённых публикационных данных:
  python Code/report_results.py
Чтобы построить их из нового прогона (изменяет таблицы и рисунки рукописи):
  python Code/report_results.py --data Evidence/reproduced_multidim
Историческая иллюстрация всегда читает Evidence/v19/gap_summary.csv.
Единица для Open-loop/точного поиска в историческом примере следует аналитически.

Сборка PDF
Нужны pdflatex и xelatex в PATH, стандартные пакеты LaTeX: geometry, fontspec,
babel с русским языком, amsmath, amssymb, amsthm, graphicx, booktabs, float,
hyperref, lmodern для английского текста. Для русского: Liberation Serif/Sans
или Times New Roman/Arial; DejaVu Sans Mono или Consolas.
  python build_papers.py
Выполняются по три прохода; результаты Paper/paper.pdf и Paper/ru/paper_ru.pdf.
build_receipt.json фиксирует хеши .tex и предупреждения финального прохода.
Выполнение научных опытов при сборке PDF не требуется.

Упаковка после успешной сборки и проверки:
  python package_release.py
Архивы и PDF этой редакции перезаписываются из текущих источников.
Исходный reading_packet_v19.zip и исходные PDF v19 не затрагиваются.
Никакой отправки в журнал или загрузки на arXiv скрипты не выполняют.
