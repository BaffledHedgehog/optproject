# Статья о Франке–Вульфе: объяснение с нуля

Начните с [учебного ноутбука](article_explained_ru.ipynb). В нём уже
сохранены выполненные ячейки, рисунки и таблицы. Код читать необязательно.
Для чтения в браузере есть [HTML-копия](article_explained_ru.html):
она скрывает код и показывает те же объяснения и статические картинки.
Формулы в HTML могут требовать доступ к MathJax в интернете.

Разбор предполагает только знакомство с обычным Франком–Вульфом.
В 18 пунктах объясняются задача с ограничениями, градиент и LMO,
ошибка и сертификат остановки, кривизна H₀/H₁, подбор шага,
подсчёт вычислений, фазовая оценка, инициализация M, удаление атомов,
точная огибающая зазора, геометрическая сходимость и конечная остановка.
В конце — чтение экспериментов статьи, пояснение приложений,
словарь обозначений и вопросы с ответами.
В начале каждого из 18 разделов есть блок «Обозначения под рукой»
с повторными определениями используемых переменных. Отдельно отмечены
различия между G и g, градиентом g* и зазором, а также разные значения
букв m и η в разных разделах.

Учебные двумерные и одномерные примеры отделены от результатов статьи.
Результаты семи методов читаются из пяти сохранённых CSV; эти архивы
и исходники статьи не изменяются. Чтение готовых графиков не требует
запуска оптимизации. При переносе ноутбука отдельно от проекта
учебные примеры выполняются, но пересчёт раздела настоящих данных
требует соответствующих файлов из PART3.

В живом Jupyter доступен необязательный ползунок для просмотра шагов
FW. Для него нужны `ipywidgets` и поддержка виджетов в клиенте.
Статические рисунки доступны независимо от виджета.

Для запуска ячеек нужны Python, NumPy, Matplotlib, IPython и Jupyter
kernel. Для воспроизводимой пересборки из корня проекта:

```powershell
python -m pip install -r PART3/Tutorial/requirements.txt
python PART3/Tutorial/build_tutorial.py --execute --html
```

Сборщик создаёт только файлы в `Tutorial`. Оптимизаторы на реальных
данных и полные бенчмарки не запускаются. Встроенные проверки сверяют
допустимость учебных точек, сертификаты, счётчики и числа сохранённых
таблиц. [Манифест](tutorial_manifest.json) хранит хеши использованных
статей, CSV, сборщика и готовых файлов. Это учебная проверка, а не
независимая математическая рецензия.

Первоисточник объяснения — [русская статья](../Paper/article_ru.pdf)
редакции от 17.10.2026. Отдельные исследовательские заметки о нижних
границах не выдаются за результаты основной статьи.
