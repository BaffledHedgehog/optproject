This archive is the corrected reconstruction; it does not replace the first archived run in `endpoint_recovery_results/`. The 324 runs use 108 Seoul/Metro configurations (two radii, all signed coordinate starts) and ordinary/dense/dyadic endpoint schedules. ## Replay audit

All 108 configurations were paired against ordinary FW for each probe schedule, yielding 216 paired paths. The auditable common prefixes contain 106,623 source points and 106,407 transitions. On every path, the common-source objective value f, FW gap G, accumulated certificate U, and every shared accepted curvature L and step alpha are exactly equal (Float64 equality). No endpoint tests were accepted. At equal update counts, paid objective-call differences satisfy `0 <= N_probe - N_ordinary <= 2d` for all 216 comparisons; maximum additional calls: 17 (the largest vertex set has 30 vertices). Every run passed feasibility/cache-accounting checks. Maximum terminal iteration was 505, so none hit the 5000-iteration cap.
