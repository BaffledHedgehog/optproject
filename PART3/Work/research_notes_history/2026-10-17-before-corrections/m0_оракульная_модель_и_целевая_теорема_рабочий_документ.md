## 1. Класс функций

**Определение 1 (класс).** Пусть H₀, H₁ ≥ 0. Через F(H₀, H₁) обозначаем множество всех f: R^d → R таких, что:
1. f дважды непрерывно дифференцируема и выпукла;
2. inf f =: f* > −∞, и argmin f ≠ ∅;
3. для всех x ∈ R^d:  ‖∇²f(x)‖_op ≤ H₀ + H₁·(f(x) − f*).

Здесь ‖·‖_op — операторная (спектральная) норма; векторы — евклидовы.

**Почему так — три тонкости.**
- *f* внутри определения.* Ограничение кривизны выражается через высоту над дном. Это делает класс «самоссылочным»: чтобы проверить, что f принадлежит F(H₀,H₁), нужно уже знать f*. Для нижней границы это центральное препятствие: противник обязан строить функцию так, чтобы условие выполнялось **глобально и одновременно** с тем, где именно дно. Классические цепочки (квадратичные) этим свойством не обладают: у них кривизна постоянна, а у функций класса кривизна обязана **падать до ≤ H₀ у самого дна**.
- *Глобальность по x.* Условие должно выполняться во всей R^d, не только вдоль траектории метода. Метод может «выпрыгнуть» из изученной области — и его ответы всё равно обязаны согласовываться с какой-то функцией класса.
- *Роль H₀ и H₁.* H₀ — «пол» кривизны (никак не убывает), H₁ — «скорость», с которой кривизна может расти с высотой. При H₁ = 0 получаем обычный H₀-гладкий класс — через это сужение будет работать лёгкая часть нижней границы.

## 2. Экземпляр задачи и параметры

**Определение 2 (экземпляр).** Экземпляр — тройка (d, f, x₀), где f ∈ F(H₀, H₁), x₀ ∈ R^d. Параметрами экземпляра называем:
- R̃ ≥ dist(x₀, argmin f) (старт не дальше R̃ от множества минимизаторов);
- F₀ = f(x₀) − f* (начальный зазор).

Дополнительно считаем, что лебеловое множество {x : f(x) ≤ f(x₀)} ограничено (для корректности рестартных схем; на нижнюю границу это ограничение не давит — «плохие» экземпляры ему удовлетворяют автоматически).

**Почему так.** Сложность мы выражаем через величины, которые «видит» метод: (H₀, H₁, R̃, F₀, ε). Это делает нашу нижнюю границу напрямую сопоставимой с верхней границей Лобанова, которая выражена в тех же параметрах. Альтернатива — выражать сложность через фактическую максимальную кривизну на уровне старта (H₀ + H₁F₀) — это соответствует «замороженной» стратегии из нашего ноутбука и заведомо хуже.

## 3. Оракул

**Определение 3 (локальный оракул первого порядка).** Оракул O_f принимает точку x ∈ R^d и возвращает пару (f(x), ∇f(x)). Локальность: ответ зависит только от поведения f в сколь угодно малой окрестности x — если f ≡ g в некоторой окрестности x, то O_f(x) = O_g(x).

**Почему так.**
- *Локальность* — стандартное требование честности: оно запрещает оракулу «подсказывать» глобальную информацию (например, где минимум) и делает нижнюю границу применимой ко всем градиентным методам. Без него нижняя граница доказывается тривиально и ничего не значит.
- *Первый порядок*: одной пары (значение, градиент) достаточно для всех схем Лобанова, значит и для нас. Расширения (координатный оракул, prox-оракул, линейный минимизационный оракул) — отдельные задачи; у Лобанова есть координатные верхние границы, так что координатная модель — потенциальное усиление на M5.

## 4. Метод и его знания

**Определение 4 (знание метода).** Методу сообщён набор K = (H₀, H₁, f*, R̃, F₀, ε): точные значения параметров экземпляра и целевая точность.

**Определение 5 (детерминированный FO-метод).** Метод A с бюджетом N — это последовательность отображений φ₁, …, φ_N и правило выхода out:
- x₁ = φ₁(K) — первая точка (функция только от знаний, без истории);
- x_{k+1} = φ_{k+1}(K; (xᵢ, f(xᵢ), ∇f(xᵢ))_{i≤k}) — каждая следующая точка — функция знаний и всей истории ответов;
- x̂_N = out(K; (xᵢ, f(xᵢ), ∇f(xᵢ))_{i≤N}) — итоговая точка.

Никаких ограничений на структуру φ (в частности, НЕ требуем принадлежности итератов span'у наблюдённых градиентов).

**Почему так.**
- *Давать методу точные (H₀, H₁, f*) — сильнейший противник.* Чем больше знает метод, тем труднее для нас нижняя граница — и тем ценнее результат. Если докажем против всеведущего метода, автоматически получим границу и для всех более «слепых».
- *Знание f* — честный выбор*, потому что (а) определение класса само «знает» f*; (б) все существующие верхние границы для класса (Лобанов) алгоритмически используют f*; (в) в практических задачах с нулевым минимумом потерь (over-parameterized модели) f* = 0 известно. Наша граница обязана «выдерживать» метод, знающий дно заранее.
- *Никакого span-ограничения* — максимальная общность. Замечание на будущее: сопротивляющийся оракул технически удобнее строит границу сначала для span-restricted методов (все практические схемы такие), а lift на произвольные — отдельный шаг; стандартно сначала доказывают span-версию.

## 5. Критерий успеха и сложность

**Определение 6 (успех).** Метод A решает экземпляр с точностью ε за N запросов, если f(x̂_N) − f* ≤ ε.

**Определение 7 (сложность класса).** Comp(F(H₀,H₁), R̃, F₀, ε) — минимальное N, при котором существует метод A, корректный для **всех** экземпляров с параметрами (H₀, H₁, R̃, F₀) (любой размерности d).

**Почему так.**
- *Критерий зазора*, а не расстояния до минимизатора: (а) так формулируются верхние границы Лобанова — прямая сопоставимость; (б) зазор не требует единственности минимизатора; (в) dist-критерий — отдельная развитая теория (ITEM и точные границы), возможное усиление на M5.
- *Свобода размерности (dimension freedom).* Мы не фиксируем d: класс включает функции любой размерности, и сложность = максимум по d. Это стандарт: на малых d задача проще (в d = 1 с известным f* — бисекция; метод сопряжённых градиентов точен за d шагов на квадратичной), поэтому содержательные нижние границы существуют только когда противнику разрешено брать d ≥ c·N. Наша цель — показать: даже при «бесконечной» размерности нельзя быстрее.

## 6. Целевая теорема

**Теорема T1 (главная гипотеза работы).** Существуют абсолютные константы c₁, c₂, c₃ > 0 такие, что для любых H₀, H₁ > 0, R̃, F₀ > 0, ε ∈ (0, F₀/2], и любого детерминированного FO-метода A со знанием K = (H₀, H₁, f*, R̃, F₀, ε) найдутся размерность d ≤ c₃·N и экземпляр (d, f, x₀) ∈ F(H₀, H₁) с параметрами (R̃, F₀), для которого

N ≥ c₁·√(H₀·R̃²/ε) + c₂·√(H₁·R̃²)·log(F₀/ε)  ⟹  f(x̂_N) − f* > ε.

**Подцели-теоремы (лестница):**
- **T1a (лёгкая часть, M2).** То же при H₁ = 0: N ≥ c·√(H₀R̃²/ε). Механизм: сужение класса до квадратичной цепочки Нестерова с ‖∇²f‖ ≤ H₀ — она лежит в F(H₀, 0), и классическая резистинг-аргументация переносится дословно.
- **T1b (ядро, M3).** То же при H₀ = 0 на подсемействе класса: N ≥ c·√(H₁·R̃²)·log(F₀/ε). Форма логарифма — часть гипотезы: задача M3 включает и уточнение формы (возможно, лог — артефакт рестартов, и истинная граница ниже; обе ветки публикуемы).
- **T2 (M4).** Объединение T1a и T1b на одном экземпляре с H₀, H₁ > 0 одновременно.

**Замечание о форме доказательства.** Доказательство нижней границы — это конструкция **сопротивляющего оракула**: стратегия ответов, при которой (i) все ответы согласованы хотя бы с одной функцией f⁻ ∈ F(H₀,H₁) с нужными параметрами, и (ii) для любой итоговой точки x̂ метода f⁻(x̂) − f⁻* > ε. Посылка (i) — это в точности «интерполяционная» задача: когда набор пар (xᵢ, f(xᵢ), ∇f(xᵢ)) продолжается до функции класса. Отсюда естественный мостик: интерполяционные условия для F(H₀,H₁) (та самая «попроще» идея уровня B) — инструмент, который автоматизирует проверку (i).
