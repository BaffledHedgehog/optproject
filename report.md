## Аннотация

В работе рассматривается задача обучения нейронной сети для бинарной классификации. Сравниваются две функции потерь: квадратичная функция потерь (MSE) и перекрёстная энтропия (Binary Cross-Entropy). Основное внимание уделено тому, как выбор функции потерь влияет на обратное распространение ошибки, величину градиентов, скорость обучения и итоговое качество классификации.

## Введение

При обучении нейронной сети функция потерь задаёт численную меру ошибки модели. Метод обратного распространения ошибки использует производную этой функции для вычисления градиентов по параметрам сети. Поэтому две разные функции потерь могут приводить к разной динамике обучения даже при одинаковой архитектуре и одинаковых данных.

Для задач классификации часто используется перекрёстная энтропия. При этом квадратичная функция потерь также формально может быть применена, если сравнивать предсказанную вероятность с истинной меткой класса. Цель работы - показать, почему на практике для классификации обычно предпочтительнее перекрёстная энтропия.

## Теория

Пусть сеть выдаёт логит `z`, а вероятность класса `1` получается через sigmoid:

```text
p = sigmoid(z)
```

Для перекрёстной энтропии в бинарной классификации:

```text
L_BCE = -y log(p) - (1 - y) log(1 - p)
```

Градиент по логиту:

```text
dL_BCE/dz = p - y
```

Для квадратичной функции потерь:

```text
L_MSE = (p - y)^2
```

Градиент по логиту:

```text
dL_MSE/dz = 2(p - y)p(1 - p)
```

Отличие состоит в множителе `p(1 - p)`. Когда sigmoid насыщается, то есть вероятность близка к 0 или 1, этот множитель становится малым. Поэтому MSE может давать слабый градиент даже при уверенно неправильном ответе. У перекрёстной энтропии такой проблемы меньше: при уверенной ошибке градиент остаётся большим.

## Эксперимент

Для эксперимента используется задача бинарной классификации `make_moons`. Это нелинейно разделимый набор данных, поэтому для решения применяется многослойный перцептрон.

Условия сравнения:

- одна и та же обучающая и тестовая выборки;
- одна и та же архитектура сети;
- одинаковая инициализация весов;
- одинаковый оптимизатор SGD с momentum;
- различается только функция потерь.

Сравниваются два варианта обучения:

- `BCE`: перекрёстная энтропия с логитами;
- `MSE`: квадратичная функция потерь между sigmoid-вероятностью и меткой класса.

## Выводы

Перекрёстная энтропия лучше подходит для обучения нейронной сети в задаче классификации, потому что её градиент по логиту равен `p - y` и остаётся достаточно большим при уверенных ошибках модели.

Квадратичная функция потерь может быть применена к классификации, но её градиент содержит множитель `p(1 - p)`. Из-за этого при насыщении sigmoid градиент уменьшается, что может замедлять обучение и ухудшать исправление сильно ошибочных предсказаний.

Эксперимент на одинаковой нейронной сети показывает, что выбор функции потерь влияет не только на численное значение loss, но и на сам процесс обратного распространения ошибки: меняются нормы градиентов, траектория обучения и итоговые метрики качества.
